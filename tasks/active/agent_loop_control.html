Task: Agent Loop Control

Status: active · Started: 2026-08-01 · Phase: 1

Goal: Improve AWOS coding-agent loop control using evidence-backed completion, focused verification, and bounded progress-aware recovery.

Spec: agent_loop_control_spec.html
Research: agent_loop_control_comparison.html

Steps

  1. Define the completion contract and focused tests.
  2. Add candidate-complete and verified-complete states.
  3. Prioritize focused verification after edits.
  4. Feed failed verification into bounded repair.
  5. Detect repeated successful no-op and ping-pong actions.
  6. Separate initial, verification, and recovery budgets under one hard cap.
  7. Run focused regression tests and update the checkpoint.

Current decision

Do not increase the default turn count first. First make completion and verification explicit, then tune the budget from measured trajectories.
