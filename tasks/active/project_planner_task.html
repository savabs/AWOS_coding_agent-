Decision Log

2026-05-19: Goal matching uses Jaccard keyword overlap (threshold 0.4) rather than LLM embeddings. Rationale: zero LLM cost, fast, deterministic, sufficient for structured project descriptions. VectorMemory can replace this in Phase 6 if needed. This decision keeps Phase 5C LLM-call-free.
2026-05-19: GoalGraph files stored as one-JSON-per-goal (not a single monolithic store). Rationale: crash isolation — a corrupt file for goal A does not affect goal B. Atomic write via .tmp + os.replace() guards against partial writes.
2026-05-19: ProjectPlanner does NOT replace Planner.plan(). Planner still generates atomic task lists. ProjectPlanner is an orchestration layer above it — deciding which tasks are new vs already-done, and persisting outcome history.
