Task: Give the Assistant Safe Control of Electron

Status: active · Governing spec: docs/specs/observer_control_spec.html

Steps

  1. ☐ Implement Electron control listener bound to localhost and token authentication. Verify unauthorized requests fail.
  2. ☐ Implement real-window status action. Verify returned state matches the visible Electron instance.
  3. ☐ Implement show, hide, focus, and reload actions. Verify lifecycle events are recorded.
  4. ☐ Implement allowlisted internal navigation. Verify external navigation is rejected.
  5. ☐ Implement semantic click and bounded fill actions. Verify unknown targets and oversized input are rejected.
  6. ☐ Implement observable cancellation dispatch without killing processes.
  7. ☑ Add CLI client and focused unit/integration tests.
  8. ☐ Run live proof with user approval, then update checkpoint and run quality gate.

Safety gate

Do not stop, restart, close, or alter the user’s current Electron run during implementation without explicit approval. Control actions must be opt-in and individually auditable.

Current proof state: CLI request construction and response verification are tested. A live status request reached the running control server but was rejected as forbidden because the existing Electron process is not aligned with the current token file. Relaunch under npm run dev is required for live proof.
