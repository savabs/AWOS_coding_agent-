Key Decisions

2026-05-19: Use cosine metric (not L2) for ChromaDB collections. Pass metadata={"hnsw:space": "cosine"} on collection creation. This gives scores in [0,1] directly from 1 - distance.
2026-05-19: VectorMemory is optional — all callers guard with if self.vector_memory is not None. This ensures zero regressions when chromadb is absent.
2026-05-19: Worker prompt injection is additive — vector_chunks=None default means no existing tests break. New context added before [TASK] block, not replacing anything.
