Task: Native Planner Holdout Integrity

Status: complete · Date: 2026-08-03

Governing spec: native_planner_holdout_integrity_spec.html

Context: The first authorized holdout was inconclusive because ambient cheap-only routing selected CheapPlanner and the oracle command targeted a directory. That trial must not be rerun under the consumed authorization.

Completed steps

1. Enforce native Planner environment policy.

Native adapter execution removes cheap-only flags and sets AWOS_NATIVE_PLANNER_REQUIRED=1; the original environment is restored afterward.

2. Disable CheapPlanner fallback under native-required policy.

Native Planner failure returns a terminal planning failure instead of silently changing model roles.

3. Report actual Planner route.

The cheap branch is labeled accurately, and native route telemetry includes planner_route_valid.

4. Validate oracle file references.

The loader rejects a resolved oracle directory and accepts a file below the private oracle root.

5. Run offline regression validation.

216 passed in the broader provider-free suite; no live rerun was made.
