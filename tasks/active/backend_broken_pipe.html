Current evidence

The real Electron control and UI submit path passed. Chat chat_1f2c9aeb / trace trace_788f3a78e3db469b872faa213e9a675b ended with Error: [Errno 32] Broken pipe before a runtime session was created. Process inspection showed port 8765 belonged to an orphaned Python server whose Electron parent was gone; the fresh Electron process reused it and inherited its closed stdout pipe. After removing the orphan and restarting, chat chat_d068c565 created runtime session rs_f340cb8cc537 and emitted normal agent tool events with no broken pipe.

The permanent fix is in awos-app/main.js and awos-app/dev-runner.js: no mismatched port fallback, and Electron/Python are managed as one detached process group. Focused supervisor tests pass. The live retry completed both tasks with failed: 0, emitted session_done, and produced no broken pipe. A clean supervisor restart then proved that 8765 is owned by the canonical Python child of Electron; touching watched awos-app/main.js replaced the complete process group and brought the backend back on 8765.
