# .hermes.md — Hermes-specific AWOS guidance

> Loaded by Hermes Agent when running from any directory in this repo.
> AGENTS.md is the shared contract; this file adds Hermes-only behaviour.

## Tool discipline
- Prefer `execute_code` for multi-step repo exploration (search → filter → report in one turn).
- Use `patch` for single-file edits; use `terminal` only for builds, tests, and git.
- Keep tool-call chains short: read → edit → verify → checkpoint.

## Test discipline
- Run focused tests first: `python3 -m pytest tests/test_<module>.py -q`
- Use `scripts/focused_test.py <file>` to get the right test scope.
- Only run the full suite at milestones.

## Context discipline
- Generate a bounded task packet: `python3 scripts/task_context.py "<task>" --task-file tasks/active/<task>.md --file path/to/relevant.py`
- Never inject all active tasks or all checkpoints into a session.

## Verification
- Every non-trivial edit must be followed by at least: `python3 -m py_compile <file>`.
- For logic changes add: `python3 -m pytest tests/test_<module>.py -q`.
- Record the result in the checkpoint.
