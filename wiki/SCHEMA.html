When to Create a New Wiki Page

Create a new wiki page when either threshold is met:

  1. Two-source rule: A topic appears in 2+ independent research notes with overlapping content.
  2. Central single-source: A topic is the primary subject of one research note AND is referenced by 3+ other documents.
Do NOT create a page for: one-off decisions (use ADRs), temporary working notes (use checkpoints), per-feature details (stay in research/spec/task triad).

HTML-First: Every Page = HTML + MD Stub

All wiki pages are HTML primary files with a thin Markdown stub for Obsidian indexing.

FilePurpose
wiki/<slug>.htmlCanonical content — the document you open and read
wiki/<slug>.mdNavigation stub — frontmatter + wiki links + pointer to HTML only

MD Stub Template

---

tags:
  - doc/wiki
  - topic/<slug>
---

HTML Document Conventions

  • Self-contained — no external CSS/JS dependencies
  • Header: title, tags, date
  • Tab navigation for multi-section docs
  • Code blocks: <pre><code> with monospace font
  • Tables for comparisons and reference data
  • End every interactive doc with a "Copy as Prompt" button
  • Never ASCII art — use SVG or CSS for diagrams

Page Structure (HTML Sections)

Every wiki page HTML must include:

  1. Definition — one paragraph explaining the concept
  2. Why it matters — why relevant to the project
  3. Current implementation — where it lives in the codebase
  4. Known limitations / open questions
  5. Cross-Reference Map — links to related docs

Frontmatter Requirements (MD Stub)

---
title: "<descriptive name>"
tags:
  - doc/wiki
  - topic/<slug>
---

For pages with contradicted facts, add:

contradicted: true
contradiction_note: "Source A says X (YYYY-MM-DD); Source B says Y (YYYY-MM-DD)"

Contradiction Handling

  1. Note both positions with their dates in the page
  2. Add contradicted: true and contradiction_note to frontmatter of the MD stub
  3. Do NOT silently overwrite old information
  4. Resolve the contradiction by consulting the canonical owner file

Page Lifecycle

StageAction
DraftAdd status: draft to MD stub frontmatter
ActiveRemove status: draft; add doc/wiki tag
DeprecatedAdd status: deprecated; note what supersedes it in the HTML header
RetiredMove to wiki/archive/; do not delete

Log Rotation

wiki/log.md is a running activity log. When it exceeds 500 entries:

  1. Copy current log to wiki/log-YYYY.md (year of oldest entries)
  2. Clear wiki/log.md and start fresh
  3. Add a link to the archived log at the top of the new log

Quick test before creating a new page:

"Does this topic appear in 2+ research notes, OR is it the primary subject of one note that 3+ other docs reference?" If neither condition is true, do not create a page.
