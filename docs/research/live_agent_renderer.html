Research: Live Agent Renderer

Status: active · Phase: 1 · Topic: live agent renderer

AWOS already has event emission, SSE, manifests, diffs, debugger reports, routing telemetry, and browser checks. The gap is a unified programmer-facing developer view.

Existing assets

  • scaffold/agent/gui_events.py persists structured events.
  • gui/server.py streams events and serves evidence.
  • gui/static/agent.html renders a partial event view inside chat.
  • tests/test_gui_events.py and tests/test_gui_browser.py provide proof foundations.

Gaps

  • No persistent full developer workspace for execution.
  • Exploration and parallel task lanes are not first-class views.
  • Worktree, replay, raw evidence, and verification are fragmented.

Constraints

Build a thin interface over existing telemetry; keep it simple, programmer-oriented, workload-neutral, and honest about observable behavior.
