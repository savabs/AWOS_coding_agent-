Research: OpenCode Go + Zen — Model Offerings & AWOS Tier Integration

doc/research phase/4 topic/model-tiering topic/opencode-go active 2026-07-09

What is OpenCode?

OpenCode (opencode.ai) is an open-source AI coding agent by Anomaly (not the archived opencode-ai/opencode repo). It offers two paid tiers:

Go Subscription

Best for AWOS: $10/month flat subscription. Generous usage limits ($60/mo value). Access to 13 open-source coding models including DeepSeek V4 Flash, MiMo-V2.5, Qwen3.7 Plus, Kimi K2.7 Code, GLM-5.2, and more.
  • Price: $5 first month, then $10/month
  • Limits: $12/5hr, $30/week, $60/month (in dollar value, not request count)
  • API: OpenAI-compatible at https://opencode.ai/zen/go/v1/chat/completions
  • Model ID format: opencode-go/<model-id>
  • Auth: Bearer token from console
  • Fallback: Can use Zen balance when limits are exceeded
  • Privacy: US/EU/Singapore hosting. Zero-retention policy. No training on your data.

Zen (Pay-as-you-go)

Curated model gateway with verified provider configurations. PAYG pricing with $20 auto-reload. Access to proprietary models (Claude, GPT, Gemini) but at higher prices than direct API (e.g., Claude Sonnet 4.5 at $3/$15 via Zen vs $3/$15 direct). Also includes free models.

Verdict for AWOS: Zen pricing is generally same or higher than direct provider APIs. Not cost-effective to route through Zen for models we already have direct keys for. However, the free models on Zen (DeepSeek V4 Flash Free, MiMo-V2.5 Free, Big Pickle, etc.) could be useful as T0 alternatives.

Key Finding

OpenCode Go is the valuable addition for AWOS. $10/month flat gives access to ~13 open-source coding models with generous limits. The key models of interest are MiMo-V2.5 ($0.14/MTok) — same price as DeepSeek V4 Flash, Qwen3.7 Plus ($0.40/MTok) — strong mid-tier open model, and Kimi K2.7 Code ($0.95/MTok) — code-specialized model. Plus it serves as backup routing when direct DeepSeek/Gemini APIs are down.

Model Quality Context

From the existing Aider polyglot benchmark data (May 2026):

  • DeepSeek V4 Flash (aka deepseek-chat) — 70.2% at $0.14/MTok (also on Go)
  • Kimi K2 — 59.1% at $0.002/req on OpenRouter (Kimi K2.7 Code is newer)
  • Qwen3 32B — 40.0% at $0.76/run (Qwen3.7 Plus/Max are newer)
  • MiMo-V2.5 (predecessor) — similar class to DeepSeek Flash, open-weight

Go model quality unverified for newer releases (Qwen3.7, Kimi 2.7, GLM-5.2, MiMo-V2.5-Pro). These need Aider polyglot or SWE-bench results to be properly tiered.

Monthly Cost Calculation

At $10/month for Go, vs direct API for DeepSeek Flash at ~$0.001/req:

  • ~10,000 requests/month on DeepSeek via Go = $10 flat (vs ~$0.14/MTok direct = ~$2-5 actual cost)
  • Go is not cheaper than direct DeepSeek per-request — it is a convenience + backup tier
  • Value prop: ONE API key, 13 models, reliable hosting, fallback from dead providers, access to models we don't have direct keys for (GLM, Kimi, Qwen Max, MiMo)

Proposed AWOS Tier Integration with OpenCode Go

Adding OpenCode Go as a new provider in the AWOS escalation ladder. The `opencode-go/` prefix is already used by the system prompt (model ID: opencode-go/deepseek-v4-flash).

Proposed Ladder with OpenCode Go

Two integration strategies:

Strategy A: OpenCode Go replaces/upgrades L2 (OpenRouter)

Since Go gives us 13 well-tested coding models with better reliability than raw OpenRouter, we can position it above or alongside OpenRouter.

L0  Gemini Flash-Lite        $0.001/req  google         — Q&A
L1  DeepSeek V4 Flash        $0.001/req  deepseek       — default worker
L2  OpenRouter               $0.002/req  openrouter     — 200+ catalog fallback
L2b OpenCode Go (MiMo-V2.5) $0.001/req  opencode-go    — T2 backup (same price)
L3  OpenCode Go (Qwen3.7+)$0.002/req  opencode-go    — mid-tier open model
L4  GPT-4o-mini              $0.003/req  openai         — fallback
L5  Claude Haiku 4.5         $0.017/req  anthropic      — BLOCKED cheap-only
L6  Claude Sonnet 4.6        $0.050/req  anthropic      — BLOCKED cheap-only

Strategy B: Add OpenCode Go as a separate provider within the rotation

Simpler: add opencode-go to _CHEAP_ROTATION alongside DeepSeek/OpenRouter/OpenAI.

]

Bottom line: Go is $10/month flat. If you use even 2 models you don't have direct keys for, it pays for itself. The real value is access + reliability + fallback — not per-request cost savings on DeepSeek Flash.

Limits Risk

Go limits can be hit. $60/month cap means ~8,000 DeepSeek Flash requests or ~1,000 Qwen3.7 Max requests before hitting the wall. Mitigation: Use Go as a backup/rotation tier, not the primary workhorse. Track usage and fall back to direct APIs when Go limits are near exhaustion.

How to Integrate OpenCode Go into AWOS

1. Add Provider to Escalation Engine

Add new EscalationLevel.OPENCODE_GO to escalation_engine.py:

class EscalationLevel(Enum):
    GEMINI_FLASH = 0
    DEEPSEEK     = 1
    OPENCODE_GO  = 2  # NEW — replaces old slot
    OPENROUTER   = 3  # shifted
    OPENAI       = 4  # shifted
    HAIKU        = 5  # shifted
    SONNET       = 6  # shifted

Add ModelSpec for Go models, e.g.:

ModelSpec(
    level=EscalationLevel.OPENCODE_GO,
    name="OpenCode Go (MiMo-V2.5)",
    model_id="opencode-go/mimo-v2.5",
    provider="opencode-go",
    cost_per_req=0.001,
    input_price=0.14,
    output_price=0.28,
    min_complexity=0,
    min_budget_remaining=0.0,
    min_failures=0,
),

2. Add Model Specs (3-4 Go models at different tiers)

We want multiple Go models at different ladder rungs. Best approach: model rotation within the same provider level, similar to how _CHEAP_ROTATION works. Or just add the Go API as a fallback at each tier level.

3. Add Worker Provider

In react_worker.py / worker.py, add an opencode-go provider branch similar to openrouter:

if provider == "opencode-go":
    client = OpenAI(
        base_url="https://opencode.ai/zen/go/v1",
        api_key=os.getenv("OPENCODE_GO_API_KEY"),
    )

4. Add to ML Router Action Space

In ml_router.py, bump N_ACTIONS from 6 to 7, add "opencode_go" to ACTION_NAMES.

5. Add API Key to Env

OPENCODE_GO_API_KEY — get from opencode.ai/auth after subscribing to Go.

Open Questions

  • Need benchmark data for newer Go models — Qwen3.7 Plus/Max, GLM-5.2, MiMo-V2.5-Pro. Their Aider polyglot scores are unknown. Need to run or find benchmarks before committing to tier placement.
  • Does Go support streaming? — OpenAI-compatible API suggests yes, but need to verify for AWOS streaming paths.
  • Can Go handle AWOS context sizes? — DeepSeek Flash handles 128K. Most models have 128K-1M context windows. Need to check per-model limits.

Priority for AWOS

HIGH: Add OpenCode Go as a fallback/rotation provider within the existing T2/T3 tiers. This is easy and protects against DeepSeek API outages.

MEDIUM: Add Qwen3.7 Plus and Kimi K2.7 Code as specific model options after benchmark validation.

LOW: Use Zen free models (data privacy concerns). Skip Zen PAYG for proprietary models.
