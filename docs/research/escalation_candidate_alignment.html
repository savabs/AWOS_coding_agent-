Research: Escalation Candidate Alignment

Status: Active | Date: 2026-07-27

Finding

The live OpenCode-only orchestrator run raised IndexError at escalation_engine.py:298: the learned router returned an action ID from its historical/static action space, while the current LADDER contains only two candidates. The code indexed LADDER[action_id] without validating the ID against the current candidate set.

Required behavior

  • The coding agent must never crash because learned routing state is stale or larger than the current ladder.
  • Unavailable or out-of-range actions must be excluded or mapped to a safe current candidate.
  • The current DeepSeek Pro through OpenCode Go baseline must remain selectable.
  • Do not introduce multi-provider routing yet; this is a baseline reliability fix.
