Research: ReAct OpenCode Go Contract

Status: active · 2026-07-31

Observed code path

  • scaffold/agent/react_worker.py selects OpenCode Go in _call_model().
  • The OpenCode branch sends temperature=0.1 and assumes message.content is a string.
  • OpenCode Go uses DeepSeek V4 Pro thinking mode by default; a reasoning-only or empty content response must be handled as a failed turn rather than raising an incidental AttributeError.

Verified sources

  • OpenCode Go documentation — endpoint and model contract.
  • DeepSeek thinking mode — temperature is not meaningful in thinking mode; disable thinking explicitly when needed.
  • DeepSeek chat completion API — response/message shape.

Risks and non-goals

Do not add provider fallbacks, retries, or tool-call protocol changes. Preserve bounded ReAct failure results and avoid logging provider content.
