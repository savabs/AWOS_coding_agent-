Test Harness Cleanup

The default pytest collection is interrupted because test_budget_hard_stop.py executes at import time and calls sys.exit. Provider connectivity tests make live calls and are not marked integration.

Decision

Refactor the budget smoke logic into a callable assertion-based pytest test and keep a guarded CLI entry point. Mark provider connectivity tests as integration-only so the default gate remains offline and reproducible.
