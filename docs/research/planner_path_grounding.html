Research: Planner Path Grounding

phase/1 · topic/planning · active · 2026-07-30

Problem

The first SWE-bench trial found the valid target src/sqlfluff/rules/L060.py during local repository inspection, but the planner contract rejected it as not grounded in exploration evidence.

Verified root cause

exploration_phase._bounded_files() and _named_files() call any(part in _SKIP_DIRS for part in path.parts) on absolute paths. A repository nested under .awos/holdout_private/... therefore has .awos in every path and all bounded files are excluded. The exact benchmark snapshot produced candidate_count=0, while the target existed.

Relevant modules

  • scaffold/agent/exploration_phase.py — bounded candidate/config file discovery.
  • scaffold/agent/orchestrator.py — strict plan grounding against snapshot candidate/hit files.
  • tests/test_planning_exploration_v1.py — deterministic exploration and plan contract tests.

Chosen correction

Compare skip-directory names against path.relative_to(root).parts, preserving the workspace-relative contract and allowing an outer workspace directory to be named .awos.

Risk: changing path filtering could include a nested source directory named .awos. Mitigation: the relative path check intentionally still excludes such directories inside the repository; only the outer absolute workspace path is ignored.

Non-goals

  • No relaxation of plan grounding.
  • No absolute-path acceptance workaround.
  • No benchmark fixture changes.
  • No provider calls.
