Research: Controlled Rerun Executor

Existing contracts

  • RerunRequest already requires source session, boundary, reason, and frozen input references.
  • RerunOutcome already defines reproduced, not reproduced, divergent, inconclusive, and error states.
  • FindingResolution preserves original findings and only creates a replacement for bounded reproduced observations.
  • DebugJournal provides append-only evidence, findings, and rerun persistence.

Decision

Add a deterministic local executor using subprocess.run with shell=False, an executable allowlist, workspace containment, timeout, output bounds, and explicit expected exit-code matching. No LLM or external provider is involved.

Outcome semantics

  • REPRODUCED: command ran in the matching environment and returned the expected exit code.
  • NOT_REPRODUCED: command ran in the matching environment but returned a different exit code.
  • DIVERGENT: requested environment or workspace contract did not match.
  • INCONCLUSIVE: timeout or missing expected result.
  • ERROR: invalid request, disallowed command, or execution error.
