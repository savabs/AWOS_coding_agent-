Research: ReAct Change Tracking

Status: Active | Date: 2026-07-27

AWOS must judge the existing coding agent from observed workspace state and verification evidence, not from an incomplete internal callback list.

Finding

The live ReAct probe changed buggy.py through the allowed workspace shell and ran three passing tests, but files_changed remained empty because the callback is attached to structured write/edit tools only. The result was therefore marked unsuccessful despite a real verified edit.

Scope

  • Preserve the existing ReAct worker and tools.
  • Detect a changed primary task file when the worker finishes and callback tracking missed it.
  • Do not treat unchanged files as edits.
  • Keep workspace confinement and verification unchanged.

Risk

Inferring changes too broadly could report false edits. Limit detection to the task's primary file and compare its final content with the content observed at task start.
