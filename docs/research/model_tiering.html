Research: Multi-Provider Model Tiering System

doc/research phase/2 topic/model-tiering active 2026-05-13

Problem & Goal

As of June 2026, GitHub Copilot switches to token-based billing. We already configured Aider + Claude API with prompt caching. The next optimization is model selection by task difficulty: use the cheapest capable model for each task type, and reserve expensive models for tasks that actually need them.

Core insight: DeepSeek-Chat (V4-Flash) scores 70.2% on the Aider polyglot benchmark at $0.14/MTok input. Claude Sonnet-4 scores 56.4% at $3/MTok. That is 21× cheaper input cost for higher benchmark quality.

Key Findings (verified)

  • DeepSeek-Chat is the default winner for coding tasks — better benchmark score than Sonnet-4 at 21× lower input cost. Tradeoff: slower (104s/case vs 30s), China-based API, no prompt caching benefit via Anthropic SDK.
  • Gemini 2.5 Pro has a FREE tier (limited RPD) that scores 79–83% polyglot — better than both Sonnet and DeepSeek for complex tasks, at zero cost until rate limit.
  • Gemini 2.5 Flash FREE tier scores 44–55% polyglot and is free for simple tasks.
  • Architect mode (cheap thinker + cheap editor) can reach Sonnet-class quality: DeepSeek R1 + Sonnet scored 64% at lower cost than Sonnet alone.
  • DeepSeek V4-Pro (deepseek-reasoner, thinking mode) scores 74% at $0.435/MTok input — at 75% discount until 2026-05-31, then $1.74/MTok.

Recommended Tier Definitions

Tier 1 — FREE

Gemini 2.5 Flash / Flash-Lite (Free Tier)

Task types: Explain code, summarize files, answer questions about a codebase, quick Q&A, check syntax, generate docstrings, write simple scripts, translate snippets.

Models: gemini/gemini-2.5-flash (44% polyglot, free up to 500 RPD) or gemini/gemini-2.5-flash-lite

Limit: Free tier uses data for model improvement. 500 RPD cap. Not for sensitive code.

Aider flag: aider --model gemini/gemini-2.5-flash

Tier 2 — CHEAP (~$0.14/MTok in)

DeepSeek-Chat (deepseek-v4-flash, non-thinking)

Task types: Standard coding tasks, bug fixes, refactoring, adding tests, implementing features from spec, any single-file or small multi-file changes.

Models: deepseek/deepseek-chat — 70.2% polyglot. Outperforms Claude Sonnet-4 at 21× lower input cost.

Limit: Slower (2–3× more latency than Sonnet). No Anthropic prompt-caching benefit. China-based API — no PII/IP.

Aider flag: aider --model deepseek/deepseek-chat

Use as default for most development work.

Tier 3 — MID ($0.30–$1.25/MTok in)

Gemini 2.5 Flash (paid) or DeepSeek-V4-Flash Thinking

Task types: When DeepSeek is slow/unavailable, or when you need thinking mode for moderately complex tasks without paying Claude prices.

Models:
• gemini/gemini-2.5-flash — 44% (no think) / 55% (24k think). Fast. $0.30/$2.50 MTok.
• deepseek/deepseek-reasoner — 74% (thinking mode, same V4-Flash price $0.14/$0.28). Use for hard single-file problems.

Aider flag: aider --model gemini/gemini-2.5-flash or aider --model deepseek/deepseek-reasoner

Tier 4 — MAIN ($1.25–$3/MTok in)

Gemini 2.5 Pro or Claude Sonnet-4

Task types: Complex multi-file architecture changes, designing new systems, tasks requiring strong reasoning + code quality, when DeepSeek fails.

Models:
• gemini/gemini-2.5-pro — 72–83% polyglot. $1.25/MTok input. FREE tier available (limited RPD).
• claude-sonnet-4-5 — 56% polyglot, but best prompt caching + AWOS integration. $3/MTok with cache reads at $0.30.

When to prefer Sonnet: When context is large (caching pays off), or when architectural reasoning + long conversation is needed.

Aider flag: aider --model gemini/gemini-2.5-pro or aider (default)

Tier 5 — HEAVY ($5–$15/MTok in)

Claude Opus-4 / o3 / o4-mini

Task types: Hardest algorithmic problems, novel research code, when lower tiers have failed, complex security audits, architecture of critical systems.

Models:
• claude-opus-4-5 — 70.7% polyglot. $15/MTok. Best for long context with caching.
• o4-mini (high) — 72% polyglot. $20/run but very strong reasoner.

Rule: Only use if Tier 4 failed or the problem is clearly exceptional.

Task Routing Decision Tree

Default tier: Tier 2 (DeepSeek-Chat). Only escalate if the task explicitly requires it.

Decision Rules (in order)

  1. Is the task just Q&A, explanation, or reading?
    → Tier 1 (Gemini Flash FREE). No code editing needed.
  2. Does it involve writing/editing code? Is the codebase non-sensitive?
    → Tier 2 (DeepSeek-Chat) as default.
  3. Is DeepSeek slow, unavailable, or is the code sensitive/proprietary?
    → Tier 3 (Gemini Flash paid) or stay in Tier 2 with patience.
  4. Has Tier 2 produced wrong/incomplete output twice?
    → Escalate to Tier 4 (Gemini Pro or Sonnet).
  5. Does the task require architecture of a new system or AWOS integration?
    → Tier 4 (Sonnet, for caching + convention awareness).
  6. Has Tier 4 failed or is this an exceptional problem?
    → Tier 5 (Opus or o3). Log the reason.

Architect Mode (Advanced)

Architect mode splits reasoning from editing: a "thinking" model plans the change, a cheaper "editor" model writes the diff. Verified on polyglot leaderboard:

  • DeepSeek R1 + Sonnet → 64.0% at ~$13/run
  • o3 (high) + gpt-4.1 → 78.2% at $18/run

Useful when: Main model is hitting edge cases but editor quality is good. Use --architect flag with --editor-model.

aider --architect --model deepseek/deepseek-reasoner --editor-model deepseek/deepseek-chat

  • Gemini free tier (GEMINI_API_KEY from AI Studio): data used for training. Use only for non-sensitive code.
  • Hardware constraint (7.6GB RAM / GTX 1650): no local models. Cloud API only.
  • Aider env var: DEEPSEEK_API_KEY and GEMINI_API_KEY in .env file, loaded by python-dotenv.
