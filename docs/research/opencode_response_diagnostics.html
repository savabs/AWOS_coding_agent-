Research: OpenCode Go Response Diagnostics

phase/1 · topic/provider-routing · active · 2026-07-31

Question

Why did the live OpenCode Go planner produce empty/non-JSON content, and what can be verified without another provider call?

Current architecture

  • scaffold/agent/fixed_provider.py creates an OpenAI-compatible client with base URL https://opencode.ai/zen/go/v1.
  • scaffold/agent/cheap_planner.py calls chat.completions.create with model deepseek-v4-pro, then parses response.choices[0].message.content as JSON.
  • tests/test_fixed_opencode_go_agent.py supplies simple fake response objects and currently covers malformed text, but not reasoning/tool/error response shapes.

Verified observations

  • The official OpenCode Go documentation lists deepseek-v4-pro and the OpenAI-compatible /v1/chat/completions endpoint.
  • The live /v1/models response lists deepseek-v4-pro.
  • The live evidence records Expecting value: line 1 column 1 for both planner attempts, meaning the parser saw an empty or non-JSON content string.
  • The live repaired trial classified the response as reasoning_only: DeepSeek returned reasoning content without ordinary JSON content.
  • The official DeepSeek docs state thinking mode is enabled by default, is disabled with extra_body={"thinking":{"type":"disabled"}}, and JSON output is requested with response_format={"type":"json_object"}.
  • The official docs state thinking mode does not support temperature meaningfully.
  • An OpenCode issue documents a DeepSeek V4 compatibility failure involving reasoning_content in custom clients. This is relevant risk evidence, not proof of this exact failure.

Risks and non-goals

Risk: logging raw provider responses could expose prompts, private repository content, or secrets. Diagnostics must record only bounded structural metadata and a short non-secret preview.
  • Do not change the provider endpoint or model.
  • Do not make another live provider request during this task.
  • Do not silently treat reasoning content or tool calls as a valid JSON plan.
  • Do not tune prompts or rewards based on the inconclusive trial.
