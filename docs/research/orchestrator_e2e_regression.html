Orchestrator E2E Regression

Internal bug investigation, 2026-07-29.

Observed failure

The legacy path calls Worker.execute_task(context_assembly=...), but the worker signature has no such parameter. The retry path therefore fails before applying a patch.

The E2E fixture patches openai.OpenAI after modules have imported their constructor, so already-bound constructors can still create a real client and trigger a network request.

Decision

Remove the unsupported keyword from legacy Worker calls. Make the regression test patch the constructors at the modules that bind them, and assert no live network client is used.
