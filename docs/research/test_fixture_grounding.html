Research: Test Fixture Grounding

Status: active · 2026-07-31

Finding

exploration_phase.py records source candidates and derives test files only from that source list. Planner output may legitimately reference a YAML test fixture outside the bounded source sample, causing strict plan validation to reject an otherwise existing test file.

Scope

Index bounded test fixtures under test/test(s) directories and include them in grounding evidence. Do not weaken path safety or allow arbitrary out-of-root files.
