Spec: Production Hardening Single Run

phase/1 · topic/production-hardening · active · 2026-08-09

Goal

Make the existing planner-to-graph single-run path deterministic and evidence-grounded, while establishing the preflight for later durable state and workspace isolation.

Allowed first-slice files

  • scaffold/agent/core/path_contract.py (new)
  • scaffold/agent/orchestrator.py (only required integration)
  • tests/test_path_contract.py (new)
  • tests/test_planner_path_grounding.py (new or extend existing coverage)
  • tests/test_planner_graph_contract_compatibility.py
  • tests/test_execution_graph_integration.py

Atomic steps

0. Baseline.

Run existing exploration, planner-contract, graph, and native execution tests. Record exact results.

Exit: baseline command and output are recorded in the task/checkpoint.

1. Path contract RED.

Write tests for root-relative normalization, traversal rejection, outside-root rejection, and evidence matching.

Exit: at least one new test fails for the expected missing API/behavior.

2. Path contract GREEN.

Implement the smallest provider-free canonical path helper and integrate only the strict validation path.

Exit: path tests and existing exploration tests pass.

3. Graph compatibility RED/GREEN.

Add the missing live-path regression only after tracing imports. Reuse validate_planner_graph; do not create a second schema.

Exit: planner-shaped input normalizes, unknown fields/dependencies fail closed, and native restoration accepts the normalized graph.

4. Live proof.

Run a deterministic fixture and record run ID/state or graph digest, verification result, and cleanup/evidence markers.

Exit: human-readable proof exists without secrets.

Verification

python3 -m pytest tests/test_path_contract.py tests/test_planner_path_grounding.py tests/test_planning_exploration_v1.py tests/test_planner_graph_contract_compatibility.py tests/test_execution_graph_integration.py -q
python3 -m py_compile scaffold/agent/core/path_contract.py scaffold/agent/orchestrator.py
python3 scripts/lsp_check.py --check scaffold/agent/core/path_contract.py --json

Stop conditions

  • Two failed fix attempts on the same file: stop and read the debug protocol.
  • Do not broaden into Docker, self-learning, UI, or unrelated lint cleanup.
  • Do not claim production-ready from this slice.
