Atomic implementation steps

  1. Make unavailable non-interactive plan approval fail closed.
  2. Disable recursive decomposition in benchmark mode after task failure.
  3. Add deterministic ReAct completion when verified acceptance evidence exists.
  4. Constrain benchmark ReAct behavior to the target workspace and task tools.
  5. Propagate the holdout budget into the orchestrator and stop before overrun.
  6. Detect stagnation from absent progress, not only repeated error signatures.
  7. Finalize a truthful timeout/error candidate report before the live runner exits.
  8. Run targeted tests after each step and the complete focused suite at the end.

Acceptance criteria

  • EOF at plan review never proceeds silently.
  • A failed task does not recursively multiply benchmark work.
  • A successful patch with passing acceptance can terminate without model finish.
  • No benchmark run exceeds its configured budget.
  • A timeout produces a valid candidate report with an unset digest until finalized.
  • All focused tests pass.
