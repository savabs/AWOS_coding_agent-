4. Persist output atomically. Write optional output only after successful comparison.
Verify: output contents equal stdout JSON.
5. Enforce exit status. Return 0 only for verified non-regressed comparisons; return 1 for regression or validation failure.
Verify: subprocess tests cover both paths.

Verify: scoped documentation lint passes.
