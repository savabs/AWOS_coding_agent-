Goal

fallback, and ensure hidden acceptance references resolve to an executable file rather than a directory.

Atomic steps

1. Enforce native Planner environment policy.

When the adapter opts into native mode, temporarily remove cheap-only routing flags and set an explicit native-required flag. Verify environment restoration.

2. Disable CheapPlanner fallback under native-required policy.

If Qwen Planner fails, return a terminal planning failure instead of calling CheapPlanner. Verify with a provider-free orchestrator test.

3. Report actual Planner route.

Emit the actual planner label and a route-validity field; native mode must not claim validity for CheapPlanner.

call a provider.
