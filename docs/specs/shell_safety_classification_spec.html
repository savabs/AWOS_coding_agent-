Spec: Shell Safety Classification

Status: active · Governing research: docs/research/shell_safety_classification.html

Goal

Prevent safe-prefix bypasses while keeping read-only shell commands usable and directing file writes to dedicated filesystem tools.

Files affected

  • scaffold/agent/tools/shell.py
  • tests/test_shell_safety.py

Atomic steps

  1. Update the classifier to reject command separators and redirection anywhere in the command.
  2. Require the allowlist pattern to match the complete command.
  3. Add focused tests for safe commands, blocked destructive commands, and chained-command bypasses.

Exit criteria

All focused tests pass; ls; rm file, ls && touch file, and redirection are blocked without explicit override, while existing read-only commands remain accepted.
