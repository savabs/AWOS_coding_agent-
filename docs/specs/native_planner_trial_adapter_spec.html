Spec: Native Planner Trial Adapter

Status: complete · Phase: 1 · Date: 2026-08-03

Goal

Make the explicitly authorized live holdout execute the OpenCode Go Qwen native Planner path instead of silently injecting a pre-planned task, while preserving existing deterministic benchmark behavior.

Files Affected

  • scaffold/agent/evaluation_v1.py — opt-in native Planner mode and route evidence.
  • scripts/run_holdout_live.py — enable native Planner mode for the live command.
  • tests/test_native_planner_trial_adapter.py — provider-free adapter behavior and evidence tests.
  • tests/test_coding_agent_minimal_e2e.py — isolate ambient routing flags so the regression test cannot reach a real provider.

  • tasks/active/native_planner_trial_adapter.html — record atomic-step completion.
  • docs/memory/checkpoint_2026-08-03.md — record session state.

Not changed: Planner model routing, worker routing, holdout digest logic, credentials, baseline artifacts, or live workspaces.

Atomic Steps

1 — Add opt-in native-Planner flag. Default remains false, preserving benchmark behavior.
2 — Suppress synthetic injection in native mode. Native mode passes no generated tasks unless explicitly supplied by the caller.
3 — Emit route evidence. Record provider, Qwen Planner model, DeepSeek worker model, and injection state without secrets.
4 — Enable native mode only for live holdout. The live command opts in; ordinary benchmark callers do not.
5 — Run offline regression validation. Keep the minimal E2E test deterministic even when ambient cheap-only environment flags are set.

Acceptance

The relevant offline suite passed with 209 passed and one known dependency warning. The holdout dry-run remains correctly blocked until its immutable baseline report and private workspace are populated.
