Spec: Trial Cost Telemetry

Goal: ensure a completed orchestrator run exposes its tracker cost to the evaluator without provider calls or report rewriting.

Research: trial_cost_telemetry.html · Task: trial_cost_telemetry.html

Allowed files

  • scaffold/agent/orchestrator.py
  • tests/test_orchestrator_e2e.py
  • tests/test_evaluation_v1.py

Atomic steps

  1. Add a regression for the producer contract. Exercise the successful final return through the mocked real orchestrator path and assert result["total_cost"] equals the live tracker total. Exit: the regression fails before the implementation change and passes after it.
  2. Expose the tracker total in the successful result. Add total_cost to the final return dictionary using the same tracker value already shown to the console. Exit: the regression passes and no provider call is made.
  3. Verify evaluator propagation. Run evaluation schema/adapter tests and assert nonzero cost survives TrialResult and EvaluationReport.mean_cost_usd. Exit: focused suite passes.

Edge Cases

  • No tracker: result cost remains 0.0.
  • Early planning/error returns remain zero because no successful execution path exists.
  • Cost is never parsed from logs or trusted from model text.
