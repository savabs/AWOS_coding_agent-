Spec: Vector Memory — Semantic Codebase & Session Retrieval

doc/spec phase/6 topic/vector-memory READY FOR IMPL 2026-05-19

Goal

Add semantic (embedding-based) retrieval to AWOS via a new VectorMemory module backed by ChromaDB + all-MiniLM-L6-v2. This enables: (1) injecting relevant code chunks into Worker prompts, (2) cross-session outcome recall, and (3) goal deduplication by cosine similarity instead of Jaccard keyword overlap.

New Dependency

chromadb>=0.6.0
sentence-transformers>=3.0.0

Both install locally, no API key required. If absent, VectorMemoryUnavailableError is raised and all callers fall back gracefully.

CodeChunk dataclass

@dataclass
class CodeChunk:
    chunk_id: str       # sha1(file_path + ":" + str(start_line))
    file_path: str
    start_line: int
    end_line: int
    text: str           # full source text (may exceed 256 tokens)
    symbol_name: str    # function/class name, or "" for sliding-window chunks
    score: float        # cosine similarity to query (0.0..1.0)

OutcomeRecord dataclass

@dataclass
class OutcomeRecord:
    task_action: str
    file_path: str
    success: bool
    session_id: str
    created_at: str
    critique: str
    score: float
