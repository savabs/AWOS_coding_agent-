Atomic steps

1. Parse paths. Require --root and allow optional manifest/baseline/candidate/output paths with safe defaults.
Verify: missing root and invalid paths fail.
2. Enforce private boundary. Resolve all inputs and require they remain under the private root; reject public fixture paths.
Verify: boundary subprocess test fails closed.
3. Delegate comparison. Invoke scripts/verify_holdout_comparison.py as a subprocess with explicit argv and no shell.
Verify: success/regression exit codes match the verifier.
4. Add pipeline tests. Cover success, regression, tampering, missing artifacts, and public path rejection.
Verify: all subprocess tests pass.
5. Document the workflow. Add a one-command example and clarify offline-only behavior.
Verify: scoped lint passes.
