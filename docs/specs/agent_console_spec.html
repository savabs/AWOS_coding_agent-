Spec: Agent Console — Transparent Back UI

doc/spec phase/4 topic/agent-console active 2026-07-12

Goal

Transform the web UI from a "CI Rescue dashboard" into a general Agent Console that shows the AWOS agent working transparently — thinking, routing, editing files, running tests — so users can feel the autonomous engineer at work, like an automatic watch with a transparent back.

Governing research: Code audit of gui_events.py, orchestrator.py, agent.html, server.py completed 2026-07-12.
Task file: agent_console.html

Files Affected

Implementation Steps

Step 1
Rebrand UI — title, tagline, empty state from CI Rescue → Agent Console

In gui/static/agent.html:

  • Change <title> from "AWOS — CI Rescue Agent" → "AWOS Agent Console"
  • Change .logo text from "🔧 AWOS" → "⚡ AWOS" and tagline from "CI Rescue Agent" → "Self-Improving Coding Agent"
  • Change empty state title from "Welcome to AWOS CI Rescue" → "Welcome to AWOS Agent Console"
  • Change empty state text from "run awos fix-ci" → "run awos run or open the chat to start working"
  • Update view tab labels
Exit condition: Open /agent in browser — title reads "AWOS Agent Console", empty state says "run awos run", no CI Rescue branding visible.
Step 2
Add dedicated thinking panel for agent reasoning stream

Add a collapsible "Agent Reasoning" panel between the main header and the terminal. This is the transparent back — it shows the model's chain-of-thought in real-time via agent_thinking events.

  • HTML: Add <div id="thinking-panel"> with a toggle header "🧠 Agent Reasoning" + collapse/expand button
  • CSS: Dimmed background (#1c2333), italic text, monospace font, max-height with scroll, smooth transition on collapse
  • JS: In handleAgentEvent, route agent_thinking events to the thinking panel in addition to the terminal log
  • Add auto-scroll to bottom on new thought
  • Show thought count badge
Exit condition: During a live session, agent_thinking events appear in the dedicated panel with dimmed italic styling, auto-scroll works, panel is collapsible.
Step 3
Update sidebar stats from CI Rescue → general agent metrics

Replace CI Rescue-specific stat cards with general agent metrics:

Old (CI Rescue)New (Agent Console)
RescuesTasks
Tests FixedModels Used (unique)

SavingsEfficiency (PEI)

Update updateStats() to track: task count, unique models used, total cost, tasks/time ratio. Update loadStats() to fetch from /api/sessions and compute agent metrics instead of /api/ci-rescue/stats.

Exit condition: Sidebar shows Tasks/Models/Cost/Efficiency with real values during/after a session.
Step 4
Wire history to general sessions API

Change loadHistory() from /api/ci-rescue/history to /api/sessions so all agent sessions appear, not just CI Rescue ones.

  • loadHistory() fetches /api/sessions (already returns all manifest sessions via GuiEventBus.list_sessions)
  • Keep the history list structure but show goal, status, task count, cost
  • Remove CI Rescue filter — show every session the agent has run
Exit condition: History list shows all agent sessions regardless of goal, click loads session events.
Step 5
Live proof: end-to-end demo with observable markers

Run the existing scripts/demo_agent_interface.sh (or update it) and verify:

  • Open http://localhost:8765/agent — title reads "AWOS Agent Console"
  • Empty state says "Welcome to AWOS Agent Console"
  • During a session: thinking panel shows agent reasoning with dimmed italic text
  • Sidebar shows Tasks/Models/Cost/Efficiency values updating live
  • All event types render correctly (plan, model_routed, task, file_edit, test_result)
Exit condition: Demo script runs without errors, all markers observed in browser.

Edge Cases

  • No active session: Empty state with welcome message, idle keepalive from SSE, thinking panel hidden
  • Session ends: Thinking panel shows final state, terminal shows session_done event, stats frozen
  • Rapid fire thoughts: Thinking panel auto-scrolls but user can scroll up to read; new thoughts append at bottom
  • Collapsed thinking panel: Events still route to terminal, just hidden from thinking panel
  • No agent_thinking events: Panel shows empty state "Waiting for agent reasoning..."
  • Multiple sessions: History lists all, clicking loads that session's events
