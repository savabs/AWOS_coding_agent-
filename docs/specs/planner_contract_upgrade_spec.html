Planner Contract Upgrade — Spec

Goal: Planner emits machine-enforceable contracts so Worker executes deterministically.

New Task Schema

{
  "task_id": 1,
  "file": "src/auth.py",
  "action": "Add JWT verify function",
  "complexity": "medium",
  "function_signature": "def verify_jwt(token: str) -> Optional[UserClaims]:",
  "interface_contract": "Must be callable as: user = verify_jwt(request.headers['Authorization'])",
  "constraints": [
    "Raise AuthError if token expired",
    "Return None if blacklisted in Redis"
  ],
  "must_not": [
    "Invent new error types beyond AuthError",
    "Add imports beyond jwt, redis, typing.Optional"
  ],
  "example_call": "user = verify_jwt('Bearer eyJ...')",
  "expected_output_shape": "Return UserClaims dataclass or None"
}

Implementation Steps

  1. 1.1 Update Planner system prompt to request contract fields
  2. 1.2 Update Planner validation to accept optional contract fields (backwards compat)
  3. 1.3 Update Worker prompt to inject contract into instructions
  4. 1.4 Update Verifier: if task has function_signature, verify generated code contains it
  5. 1.5 Smoke test: run Planner on "add auth middleware", verify contracts appear
  6. 1.6 Update Orchestrator to pass full task dict through (already does, confirm)

Testing Plan

  • Planner produces contracts on a sample goal (no API key: mock)
  • Worker prompt includes contract section when present
  • Verifier catches missing signature when contract specifies one

Edge Cases

  • Contract fields absent → old behavior unchanged
  • Contract contradicts existing code → Verifier soft-fail, log warning
  • Sonnet refuses to emit contracts for vague goals → graceful degradation
