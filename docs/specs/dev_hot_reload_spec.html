Spec: Development Supervisor

Status: active · Date: 2026-07-28

Goal

Allow one long-running development command to keep the real Electron app aligned with source changes without manual restart instructions.

Contract

  1. npm run dev starts a supervisor from awos-app.
  2. The supervisor spawns Electron with inherited stdin/stdout/stderr and the existing working directory.
  3. It watches an explicit source list: main.js, preload.js, package.json, ../gui/server.py, and observer Python modules.
  4. Changes are debounced for 250ms, then the Electron child receives SIGTERM and is relaunched.
  5. Ctrl+C stops the watcher and child cleanly; production npm start is unchanged.
  6. The supervisor never accepts a command, path, or shell fragment from a network/API caller.

Atomic steps

  1. ☑ Add the supervisor with explicit watch list and safe child lifecycle.
  2. ☑ Add the npm run dev script.
  3. ☑ Add unit/source tests for watch list, debounce, and shutdown behavior.
  4. ☑ Run a live proof: edit a watched file and verify the child PID changes while the control health endpoint returns again.

Exit criteria

The user starts the development app once and does not manually restart it after each watched source edit. A restart is still visible and auditable; active work is not silently claimed to survive a process restart.
