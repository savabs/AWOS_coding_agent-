Spec: Read-only Observer Follow

Status: active · Date: 2026-07-28

Goal

Resolve and follow the user's current UI-to-backend run through existing observer events without controlling Electron.

Contract

The live proof also requires the chat bridge and orchestrator call signatures to remain compatible; this is a compatibility seam, not a new control system.

  • scaffold/agent/gui_chat.py and scaffold/agent/orchestrator.py must accept the existing chat-to-agent compatibility arguments.
  • resolve_observer_session(chat_id, trace_id) scans validated assistant-safe backend ledgers and returns one session, no match, or explicit ambiguity.
  • python3 awos.py observe follow follows the latest UI action, prints a bounded ordered timeline, and never mutates AWOS.
  • An explicit --chat, --trace, or --session filter is supported for deterministic recovery.
  • Unknown or stale cursors produce a gap/snapshot instruction, not guessed state.

Safety

  • Read-only filesystem and HTTP access.
  • Assistant-safe projection only.
  • No control endpoint, process launch, GUI input, or raw prompt logging.

Atomic steps

  1. Add correlation resolver and tests.
  2. Add follow projection/CLI command.
  3. Validate explicit ambiguity and not-found behavior.
  4. Run focused tests and a local live read-only proof.
