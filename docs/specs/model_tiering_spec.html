Spec: Model Tiering — Multi-Provider Routing

doc/spec phase/2 topic/model-tiering active 2026-05-13

Governing Research

See docs/research/model_tiering.html for full benchmark data, pricing tables, and tier definitions.

Objective

Configure the workspace so any Aider session can be launched at the correct cost tier with a single command. Routing decisions are encoded in CONVENTIONS.md (read by every Aider session) and in Makefile targets.

Scope: Edit only .env, scripts/token_report.py, Makefile, CONVENTIONS.md, memories/repo/project_structure.md. Do not touch .aider.conf.yml (keep Sonnet as safe default).

Atomic Steps

Step 1.1
Add DEEPSEEK_API_KEY and GEMINI_API_KEY to .env

Append two placeholder lines to .env. Values are empty — user fills them in. Include comment with where to get each key.

# DeepSeek API — https://platform.deepseek.com/api_keys
DEEPSEEK_API_KEY=

# Google Gemini API — https://aistudio.google.com/apikey
GEMINI_API_KEY=
Exit condition: grep DEEPSEEK_API_KEY .env returns the line. No secrets committed.
Step 1.2
Expand PRICING dict in scripts/token_report.py

Add Gemini 2.5 Pro, Gemini 2.5 Flash, DeepSeek-Chat, DeepSeek-Reasoner entries to the existing PRICING dict. Preserve all existing Claude entries. Add a comment marking the addition date.

Exit condition: python3 -c "from scripts.token_report import PRICING; print(list(PRICING))" includes deepseek-chat and gemini-2.5-flash without errors.
Step 1.3
Add tier Makefile targets

Add four new targets to Makefile: dev-cheap, dev-think, dev-mid, dev-pro. Each target runs aider with the appropriate --model flag. dev-cheap and dev-think also prewarm the Claude cache (CONVENTIONS.md is still read). Add a help target that lists all targets.

Exit condition: make help outputs all 8 targets (help, dev, dev-cheap, dev-think, dev-mid, dev-pro, prewarm, report) with descriptions.
Step 1.4
Add MODEL ROUTING section to CONVENTIONS.md

Append a new section after the existing content. Must stay above 1024 tokens total (currently 1505, so addition is safe). Include: tier table, decision rules, and ESCALATE/STAY heuristics.

Exit condition: grep -c "MODEL ROUTING" CONVENTIONS.md = 1. File is still ≥1024 tokens (run prewarm to verify cache still created).
Step 1.5
Update memories/repo/project_structure.md

Update the project_structure file: add multi-provider status (DeepSeek key pending, Gemini key pending), add model tier table, update "Key modules" list to include new Makefile targets.

Exit condition: File contains "deepseek" and "gemini" entries in the model cost table.

Non-Goals (out of scope)

  • Do not create a Python routing script or auto-detection logic — manual tier selection is sufficient.
  • Do not modify .aider.conf.yml — keep Sonnet as the default (safe fallback).
  • Do not add OpenRouter token tracking — out of scope for this phase.
