Spec: TestRunner + Test-as-Reward (Phase 5A)

doc/spec phase/5 topic/self-learning topic/test-runner active 2026-05-19

Goal

Add a TestRunner module that auto-detects the project's test framework, runs tests after every code patch, and feeds the pass rate into the LinUCB reward signal — replacing binary syntax-only success with continuous test-grounded reward.

Governing research: test_runner_reward.html
Task file: test_runner_reward_task.html

Interface Contract

# scaffold/agent/test_runner.py
from dataclasses import dataclass
from typing import Optional, List

@dataclass
class TestConfig:
    """Detected test framework configuration for a project."""
    runner: str        # "pytest" | "jest" | "vitest" | "make" | "go" | "cargo" | None
    command: List[str] # shell command tokens, e.g. ["pytest", "--tb=short", "-q"]
    timeout_sec: int   # default 60

@dataclass
class TestResult:
    """Result of a single test execution."""
    passed: int
    failed: int
    errors: int
    pass_rate: float   # 0.0–1.0, 0.0 if timed_out or no tests
    raw_output: str    # stdout + stderr, for SelfCorrectionEngine injection
    timed_out: bool
    test_command: List[str]

class TestRunner:
    """Language-agnostic test executor."""

    def __init__(self, project_root: str = ".", timeout_sec: int = 60):
        self.project_root = project_root
        self.timeout_sec = timeout_sec

    def detect(self) -> Optional[TestConfig]:
        """Inspect project_root and return a TestConfig, or None if no tests detected."""

    def run(self, changed_files: Optional[List[str]] = None) -> TestResult:
        """Run tests using detected config. Returns TestResult with pass_rate."""

    def _parse_pytest(self, stdout: str, stderr: str) -> TestResult:
        """Parse pytest --tb=short -q output."""

    def _parse_jest(self, stdout: str, stderr: str) -> TestResult:
        """Parse jest --passWithNoTests output."""

    def _parse_generic(self, stdout: str, stderr: str, command: List[str]) -> TestResult:
        """Fallback regex: X passed / X failed / X errors."""

Implementation Steps

Each step is atomic: changes one thing, tests one thing, proves one thing.

Step 1
Create scaffold/agent/test_runner.py with dataclasses and skeleton

Create TestRunner, TestConfig, TestResult as defined above. Add _detect_pytest(), _detect_jest(), _detect_vitest(), _detect_make(), _detect_go(), _detect_cargo() helpers. Each helper checks for signal files and returns a TestConfig or None.

Exit condition: pytest tests/test_test_runner.py::TestDetection -x passes (test cases written in Step 6).
Step 2
Implement TestRunner.run() with subprocess + timeout

Run the detected command via subprocess.run(..., timeout=timeout_sec, capture_output=True, cwd=project_root). On TimeoutExpired, return TestResult(passed=0, failed=0, errors=0, pass_rate=0.0, timed_out=True). On success, dispatch to the correct parser.

Exit condition: pytest tests/test_test_runner.py::TestRun -x passes with mocked subprocess.
Step 3
Implement pytest output parser

Parse pytest summary line: 3 passed, 1 failed, 0 errors in 0.12s. Regex: r'(\d+) passed(?:, (\d+) failed)?(?:, (\d+) errors?)?'. Return counts and pass_rate. Store full stdout + stderr in raw_output.

Exit condition: Parser correctly extracts (passed, failed, errors, pass_rate) from 5 sample pytest outputs (all pass, 1 fail, errors, no tests, collection error).
Step 4
Implement jest and generic fallback parsers

Jest: parse Tests: 2 passed, 1 failed, 3 total. Generic: regex r'(\d+)\s*passed.*?(\d+)\s*failed' and r'(\d+)\s*error'. Both return TestResult with counts.

Exit condition: Both parsers extract correct counts from sample outputs.
Step 5
Add safety guard: AWOS_SAFE_TO_RUN_TESTS

In TestRunner.run(), if os.environ.get("AWOS_SAFE_TO_RUN_TESTS") != "1": return TestResult(..., pass_rate=0.0, timed_out=False) with a note in raw_output. This prevents accidental destructive side effects.

Exit condition: pytest tests/test_test_runner.py::TestSafetyGuard -x passes.
Step 6
Write unit tests for TestRunner

Create tests/test_test_runner.py with:

  • TestDetection — pytest, jest, vitest, make, go, cargo, unknown (7 cases)
  • TestParse — pytest all-pass, 1-fail, errors, no-tests, jest all-pass, generic
  • TestRun — mock subprocess.run with side_effect, timeout, success, failure
  • TestSafetyGuard — env not set → pass_rate=0; env set → runs
  • TestIntegration — full detect → run → parse pipeline

Exit condition: All tests in tests/test_test_runner.py pass.
Step 7
Wire TestRunner into Orchestrator

After Verifier.verify_and_apply() returns success=True in Orchestrator.execute():

  1. Instantiate TestRunner(project_root=self.project_root or ".")
  2. test_result = runner.run(changed_files=[file_path])
  3. Store test_result in task["test_result"] for SelfCorrectionEngine
  4. Call self.escalation.record_outcome(task, reward=test_result.pass_rate, cost=cost, model_name=model_name)
If Verifier fails, skip TestRunner (already retrying via SelfCorrectionEngine).

Exit condition: E2E test passes: orchestrator receives float reward matching pass_rate.
Step 8
Verify EscalationEngine.reward logic uses test_reward

Confirm EscalationEngine.record_outcome() passes the reward kwarg through to Episode. Confirm Episode.reward formula uses the provided reward (not overriding it). If reward kwarg is None, fall back to existing computed reward.

Exit condition: pytest tests/test_ml_meta_controller.py still passes; Episode.reward field is float when test_reward provided.
Step 9
Run full test suite — no regressions

pytest tests/ -x — all tests pass, no failures in existing modules.

Exit condition: 0 failures across all test files.

Edge Cases

  • No tests detected: TestRunner.detect() returns None. Orchestrator skips TestRunner, falls back to syntax-only reward (existing behavior — zero regression).
  • Test collection error: e.g. import error in test file. subprocess.run returns non-zero exit. Parser extracts 0 passed, 0 failed, treat as pass_rate=0.0. Raw output sent to SelfCorrectionEngine.
  • Timeout: pass_rate=0.0, timed_out=True. Orchestrator falls back to syntax-only reward. Log warning.
  • Environment variable not set: Safety guard returns pass_rate=0.0 with note. No subprocess launched. Zero regression.
  • Unknown runner type: Generic parser handles any output with "X passed / Y failed" pattern.
