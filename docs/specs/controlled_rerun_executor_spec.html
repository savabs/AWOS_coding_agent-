Spec: Controlled Rerun Executor

Research: controlled_rerun_executor.html

  1. Create an allowlisted, shell-free local command executor.
  2. Validate workspace containment, environment identity, frozen references, timeout, and output bounds.
  3. Classify matching, non-matching, divergent, inconclusive, and invalid executions.
  4. Append rerun evidence, deterministic proof findings, and the outcome to DebugJournal.
  5. Add regression tests covering all outcome classes and append-only persistence.

Non-goals

No arbitrary shell commands, no model calls, no remote execution, no automatic patching, and no deletion or mutation of original findings.
