Task: react_change_tracking.html

Goal

Make the existing ReAct worker recognize a primary task-file edit performed through an allowed shell command when structured-tool callbacks did not fire.

Files in scope

  • scaffold/agent/react_worker.py
  • tests/test_react_worker.py or a focused ReAct regression test

Atomic steps

  1. Detect primary-file divergence. Compare the final primary task file with its initial content only when the task requires edits and no tracked files exist. Exit: a changed primary file is added once to files_changed.
  2. Preserve unchanged-file behavior. Exit: a task that finishes without changing its primary file does not become successful merely because it has a passing test.
  3. Prove live ReAct success. Run the controlled benchmark task with OpenCode Go and verify the result reports success, changed file, passing tests, cost, and evidence.

Acceptance

  • No false changed-file report for unchanged content.
  • Structured tool tracking remains unchanged.
  • Shell edits remain workspace-confined.
  • Only verified test outcomes count as success.
