Spec: Tool Reflection / Success Matrix

doc/spec phase/8 topic/tool-reflection active 2026-05-20

Goal

Wire the existing ToolPerformanceTracker.success_matrix() end-to-end: enrich records with latency + cost, display the matrix as a post-run panel, and feed recommend_model() as a cold-start-safe soft routing hint into EscalationEngine — so that empirically successful model/task-type pairings improve future routing with zero new storage or ML overhead.

Governing research: tool_reflection.html
Task file: tool_reflection_task.html

Implementation Steps

Each step is atomic: changes one thing, tests one thing, proves one thing.

Step 1
Fix JSONL storage in ToolPerformanceTracker

In performance_tracker.py: change _load() to read line-by-line JSONL (one JSON object per line) instead of a JSON array. Change _append_to_disk() to write one JSON line (already does this). Add migration: if file starts with [, read as JSON array and rewrite as JSONL. No new public API.

Exit condition: ToolPerformanceTracker(tmp_dir).record(...) called 3×, then a new ToolPerformanceTracker(tmp_dir) loads and len(tracker._records) == 3.
Step 2
Add _classify_task_type() helper to ToolPerformanceTracker

Private static method that maps an action_text string → one of {"bug_fix", "refactor", "new_feature", "architecture", "test", "general"} using the keyword sets already defined in ml_router.py (_BUG_FIX_KW etc). Priority order: bug_fix > test > refactor > architecture > new_feature > general. No imports added to performance_tracker.py — inline the keyword sets as module-level constants.

Exit condition: _classify_task_type("fix the crash in auth") returns "bug_fix"; _classify_task_type("add user registration") returns "new_feature"; _classify_task_type("update README") returns "general".
Step 3
Add matrix_display() method to ToolPerformanceTracker

New public method that calls self.success_matrix() and returns a formatted multi-line string for printing — same style as the observability panel display() methods. If no data (<3 total records), return None. Format: header line, then per-row: model name | task_type | count | success_rate% | avg_latency_ms | top_error.

Exit condition: After recording 5 entries with model="deepseek" and task_type="bug_fix", matrix_display() returns a non-None string containing "deepseek" and "bug_fix" and a percentage.
Step 4
Enrich performance.record() calls in orchestrator with latency_ms, cost_usd, semantic task_type

In orchestrator._execute_single_task(), both record() call sites (lines ~766 and ~781): add latency_ms=(_time.time() - _span.worker_start_ts) * 1000, cost=esc_decision.spec.cost_per_req, and replace task_type=task.get("complexity", "unknown") with task_type=self.performance._classify_task_type(task.get("action", "")). No other changes.

Exit condition: After a mock run, performance.get_stats(model="...", task_type="bug_fix") returns a dict where avg_latency_ms and avg_cost are not None.
Step 5
Print success matrix panel (Phase 5) in execute_feature

In orchestrator.execute_feature(), after the Phase 4 async projection print block (line ~398), add Phase 5: call self.performance.matrix_display() and print if not None. Follow the exact pattern of phases 1–4 (try/except import, guard on None). Label the section # ── Phase 5: Tool Reflection — success matrix ──.

Exit condition: After seeding performance tracker with >=3 records, execute_feature() stdout contains the matrix panel header (no crash on zero records).
Step 6
Wire recommend_model() as soft hint in EscalationEngine.decide()

In escalation_engine.py, in decide(), after the LinUCB block: add a guard — if LinUCB is in cold-start (total_episodes < linucb.min_samples) AND a performance_tracker is attached to the engine, call performance_tracker.recommend_model(task_type, candidates). If it returns a non-None model name, map it to the nearest EscalationLevel and set suggested_level (soft, not hard). Accept performance_tracker=None in EscalationEngine.__init__ (already accepts it implicitly through the kwargs). This ensures cold-start uses historical data; once LinUCB has learned (20+ episodes) it takes over.

Exit condition: Unit test: create EscalationEngine with a mock performance_tracker returning "deepseek", LinUCB cold-start. decide(task, failure_count=0, budget_remaining=20) returns a decision whose spec name contains "deepseek" or the equivalent tier.
Step 7
Write tests/test_tool_reflection.py (14 tests)

Create new test file. Tests: (1) JSONL roundtrip after reload, (2) JSONL migration from old JSON array format, (3–4) _classify_task_type: bug_fix and new_feature, (5) _classify_task_type general fallback, (6) success_matrix shape with 5 records, (7) success_matrix min_count filter, (8) matrix_display returns None on empty, (9) matrix_display returns string with model name, (10) best_model_for returns None when no data, (11) best_model_for returns correct model with data, (12) recommend_model with multiple candidates, (13) orchestrator performance.record() enrichment via mock (latency_ms non-None), (14) escalation soft hint: cold-start uses performance recommend_model.

Exit condition: pytest tests/test_tool_reflection.py -v shows 14 passed, 0 failed.
Step 8
Full test suite — zero regressions

Run pytest scaffold/tests/ tests/ -x -q. All previously passing tests must still pass. No new skips beyond the 39 existing ones (which skip due to missing optional deps).

Exit condition: pytest reports 448+ passed (434 existing + 14 new), 0 failed, <= 39 skipped.

Edge Cases

  • Empty performance.json on first run — matrix_display() returns None, panel silently skipped. No crash.
  • Corrupt JSON lines in performance.json — _load() skips malformed lines with a warning log (same pattern as RewardStore). Surviving records still usable.
  • LinUCB active (20+ episodes) — performance soft hint is bypassed entirely; LinUCB has better signal. No double-application.
  • All candidates have < min_count records — recommend_model() returns None; EscalationEngine falls back to heuristics unchanged.
  • _span.worker_start_ts not yet set — guard: latency_ms = (_time.time() - _span.worker_start_ts) * 1000 if _span.worker_start_ts else None.
  • Old performance.json as JSON array (migration) — _load() detects first char == '[', reads as JSON array, rewrites file as JSONL. One-time migration, transparent to caller.
