1. Problem

Current AWOS flow: Worker receives entire file content (up to 300+ lines) + CodebaseIndex raw results (up to 4,000 tokens). The LLM must figure out WHERE to edit from all this noise.

Root cause of edit failures: Not that the LLM can't write the fix — it's that it's attending to the wrong part of the file. Give it just the relevant 5 functions and first-attempt success rate jumps significantly.

What AWOS currently does vs. what Agentless does:

StepAWOS (current)Agentless / P1.5 target
Find relevant filesCodebaseIndex vector search (flat)Repo structure format → LLM picks top-N files
Find relevant functionsReturn raw chunk text (mixed content)Skeleton format (signatures only) → LLM picks functions
Find edit locationWorker figures it out from full contextFunction bodies → LLM identifies (file, line_start, line_end)
Context tokens to worker2,000–8,000 (unfiltered)300–800 (just relevant function bodies)

2. The Three-Level Approach

INPUT: task_action + error_trace + project_root │ ▼ LEVEL 1 — File Localization Repo structure format (dir tree, no code content) + task_action → cheap LLM call → top-3 suspicious files │ ▼ LEVEL 2 — Symbol Localization Skeleton format of top-3 files (class headers + method signatures + docstrings only) + task_action + error_trace → cheap LLM call → list of (file, symbol_name) pairs │ ▼ LEVEL 3 — Edit Location Identification Full body of selected symbols only + task_action + error_trace → cheap LLM call → list of EditLocation(file, start_line, end_line, confidence, reason) │ ▼ OUTPUT: [EditLocation, ...] — passed to worker as focused context

2.1 Cost Analysis

StepTokens InModelCost (DeepSeek)
L1: File localization~500 (repo tree)T1 Gemini Flash~$0.0001
L2: Symbol localization~1,000 (skeletons)T1 Gemini Flash~$0.0002
L3: Edit location~800 (function bodies)T2 DeepSeek~$0.0001
Total overhead~2,300—~$0.0004
Saving on worker-5,000 context tokens—-~$0.003
💰 Net: ~8x more expensive to localize, but saves ~8x on worker context = break-even on cost + significantly better accuracy.

3. Implementation: FaultLocalizer

# scaffold/agent/fault_localizer.py from dataclasses import dataclass, field from pathlib import Path import ast @dataclass class EditLocation: file: str start_line: int end_line: int symbol_name: str # function or class name confidence: float # 0.0–1.0 reason: str # LLM explanation @dataclass class LocalizationResult: task_action: str suspicious_files: list[str] # L1 output suspicious_symbols: list[tuple[str,str]] # L2 output: [(file, symbol_name)] edit_locations: list[EditLocation] # L3 output total_context_tokens: int # how much was used class FaultLocalizer: """ Three-level hierarchical localization. Agentless architecture. Cheap calls (Gemini Flash / DeepSeek) only. """ def __init__(self, project_root: str, cheap_llm_caller, mid_llm_caller=None): self.project_root = Path(project_root) self.cheap_llm = cheap_llm_caller # Gemini Flash (T1) self.mid_llm = mid_llm_caller or cheap_llm_caller # DeepSeek (T2) # ─── PUBLIC API ─────────────────────────────────────────────── def localize( self, task_action: str, error_trace: str = "", top_files: int = 3, top_symbols: int = 8, ) -> LocalizationResult: """ Run all three levels. Returns edit locations with confidence scores. Falls back gracefully: if any level fails, use what's available. """ # Level 1 suspicious_files = self._localize_files(task_action, error_trace, top_files) if not suspicious_files: return LocalizationResult(task_action, [], [], [], 0) # Level 2 suspicious_symbols = self._localize_symbols( task_action, error_trace, suspicious_files, top_symbols ) if not suspicious_symbols: # Fall back: return file-level result only return LocalizationResult(task_action, suspicious_files, [], [], 0) # Level 3 edit_locations = self._localize_edit_lines( task_action, error_trace, suspicious_symbols ) total_tokens = self._estimate_context_tokens(edit_locations) return LocalizationResult( task_action=task_action, suspicious_files=suspicious_files, suspicious_symbols=suspicious_symbols, edit_locations=edit_locations, total_context_tokens=total_tokens, ) def format_for_worker(self, result: LocalizationResult) -> str: """ Format localization result as the focused context block for worker. Replaces the raw CodebaseIndex dump. """ if not result.edit_locations: return "" lines = ["## Localized Edit Targets:\n"] for loc in result.edit_locations[:5]: # max 5 locations body = self._extract_lines(loc.file, loc.start_line, loc.end_line) lines.append(f"### {loc.file}:{loc.start_line}-{loc.end_line} — `{loc.symbol_name}`") lines.append(f"_Confidence: {loc.confidence:.0%} | Reason: {loc.reason}_") lines.append(f"```python\n{body}\n```\n") return '\n'.join(lines)

4. Key Private Methods

4.1 Level 1 — File Localization

def _build_repo_structure(self) -> str: """ Build Agentless-style repo structure format. Directory tree with file names, no code content. """ lines = [] for path in sorted(self.project_root.rglob("*.py")): # Skip test dirs, __pycache__, venv parts = path.parts if any(p in parts for p in ("__pycache__", ".venv", "venv", "node_modules")): continue rel = path.relative_to(self.project_root) indent = " " * (len(rel.parts) - 1) lines.append(f"{indent}{rel}") return '\n'.join(lines) def _localize_files( self, task_action: str, error_trace: str, top_n: int ) -> list[str]: """Level 1: cheap LLM call to identify suspicious files.""" repo_structure = self._build_repo_structure() prompt = f"""You are a fault localization assistant. Repository structure: {repo_structure} Task: {task_action} {"Error trace: " + error_trace if error_trace else ""} List the top {top_n} files most likely to need editing to complete this task. Reply with ONLY a JSON array of file paths relative to project root: ["path/to/file1.py", "path/to/file2.py"] """ response = self.cheap_llm(prompt, max_tokens=200) try: import json, re match = re.search(r'\[.*\]', response, re.DOTALL) if match: files = json.loads(match.group()) # Validate all paths exist return [f for f in files if (self.project_root / f).exists()][:top_n] except Exception: pass return []

4.2 Level 2 — Symbol Localization (Skeleton Format)

def _build_skeleton(self, file_path: str) -> str: """ Build Agentless skeleton format: class/function headers + signatures only. No function bodies. Much cheaper to send than full file. """ try: source = (self.project_root / file_path).read_text() tree = ast.parse(source) except (SyntaxError, OSError): return "" lines = source.split('\n') skeleton_lines = [] for node in ast.walk(tree): if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)): # Signature line only sig_line = lines[node.lineno - 1].strip() skeleton_lines.append( f" {sig_line} # lines {node.lineno}-{node.end_lineno}" ) # First docstring line if present if (node.body and isinstance(node.body[0], ast.Expr) and isinstance(node.body[0].value, ast.Constant)): doc = node.body[0].value.value.split('\n')[0].strip() skeleton_lines.append(f' """{doc}"""') elif isinstance(node, ast.ClassDef): skeleton_lines.append( f"class {node.name}: # lines {node.lineno}-{node.end_lineno}" ) return '\n'.join(skeleton_lines) def _localize_symbols( self, task_action: str, error_trace: str, files: list[str], top_n: int, ) -> list[tuple[str, str]]: """Level 2: LLM identifies relevant symbols from skeleton.""" skeletons = [] for f in files: sk = self._build_skeleton(f) if sk: skeletons.append(f"## {f}\n{sk}") if not skeletons: return [] prompt = f"""You are a fault localization assistant. Task: {task_action} {"Error trace: " + error_trace if error_trace else ""} Code structure of relevant files: {chr(10).join(skeletons)} List the top {top_n} functions or classes most likely to need editing. Reply with ONLY a JSON array: [["file_path", "symbol_name"], ...] """ response = self.cheap_llm(prompt, max_tokens=300) try: import json, re match = re.search(r'\[.*\]', response, re.DOTALL) if match: symbols = json.loads(match.group()) return [(s[0], s[1]) for s in symbols if len(s) == 2][:top_n] except Exception: pass return []

4.3 Level 3 — Edit Location (Line-Level)

def _localize_edit_lines( self, task_action: str, error_trace: str, symbols: list[tuple[str, str]], ) -> list[EditLocation]: """Level 3: Extract exact function bodies, ask for line-level locations.""" bodies = [] symbol_meta = {} for file_path, symbol_name in symbols: body, start, end = self._extract_symbol_body(file_path, symbol_name) if body: bodies.append(f"## {file_path}::{symbol_name} (lines {start}-{end})\n{body}") symbol_meta[f"{file_path}::{symbol_name}"] = (file_path, start, end) if not bodies: return [] prompt = f"""You are a fault localization assistant. Task: {task_action} {"Error trace: " + error_trace if error_trace else ""} Relevant code: {chr(10).join(bodies[:5])} Identify the exact edit locations. Reply ONLY with JSON: [ {{ "file": "path/to/file.py", "symbol_name": "function_name", "start_line": 42, "end_line": 58, "confidence": 0.9, "reason": "brief reason why this needs editing" }} ] """ response = self.mid_llm(prompt, max_tokens=400) try: import json, re match = re.search(r'\[.*\]', response, re.DOTALL) if match: locs = json.loads(match.group()) result = [] for loc in locs: result.append(EditLocation( file=loc["file"], start_line=loc.get("start_line", 1), end_line=loc.get("end_line", 1), symbol_name=loc.get("symbol_name", ""), confidence=float(loc.get("confidence", 0.7)), reason=loc.get("reason", ""), )) return result except Exception: pass return [] def _extract_symbol_body( self, file_path: str, symbol_name: str ) -> tuple[str, int, int]: """Extract full body of a named function/class. Returns (body, start, end).""" try: source = (self.project_root / file_path).read_text() tree = ast.parse(source) lines = source.split('\n') except (SyntaxError, OSError): return "", 0, 0 for node in ast.walk(tree): if (isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)) and node.name == symbol_name): body = '\n'.join(lines[node.lineno - 1:node.end_lineno]) return body, node.lineno, node.end_lineno return "", 0, 0 def _extract_lines(self, file_path: str, start: int, end: int) -> str: """Extract lines start..end from file.""" try: lines = (self.project_root / file_path).read_text().split('\n') return '\n'.join(lines[start - 1:end]) except OSError: return "" def _estimate_context_tokens(self, locations: list[EditLocation]) -> int: total = 0 for loc in locations: body = self._extract_lines(loc.file, loc.start_line, loc.end_line) total += int(len(body.split()) * 1.3) return total

5. Integration into Orchestrator

# In orchestrator.py — _execute_single_task(): # BEFORE (current): context = self.codebase_index.query_code(task["action"], n_results=5) # → sends 2,000-8,000 tokens of mixed content to worker # AFTER (P1.5): localizer = FaultLocalizer( project_root=self.project_root, cheap_llm_caller=self._cheap_call, # Gemini Flash mid_llm_caller=self._mid_call, # DeepSeek ) loc_result = localizer.localize( task_action=task["action"], error_trace=task.get("error_trace", ""), ) focused_context = localizer.format_for_worker(loc_result) # → sends 300-800 tokens of precisely targeted function bodies # Inject into task for worker task["focused_context"] = focused_context task["edit_locations"] = loc_result.edit_locations

5.1 Worker Receives EditLocations (Block B)

# In worker._build_file_and_rag_context() (P2.1.5): # If task has "focused_context", use that instead of raw RAG: if task.get("focused_context"): # Use localizer output — already budgeted and focused return task["focused_context"] else: # Fall back to P2 three-block RAG approach return self._build_rag_context(file_content, task, codebase_index)
