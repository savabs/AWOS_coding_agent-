Spec: Holdout Metadata Consistency

Goal: make holdout dry-run reject a baseline report that does not belong to the declared trial.

Research: holdout_metadata_consistency.html · Task: holdout_metadata_consistency.html

Allowed files

  • scripts/run_holdout_live.py
  • tests/test_holdout_live.py

Atomic steps

  1. Validate the baseline artifact digest. Require the manifest digest to equal the actual baseline file digest. Exit: stale or tampered baseline fails before provider authorization.
  2. Validate baseline identity metadata. Require corpus ID, environment identity, and exact task coverage to match the manifest. Exit: controlled8-style label mismatch fails during dry-run.
  3. Preserve valid dry-run behavior. Add a valid baseline fixture and assert dry-run still succeeds. Exit: focused holdout tests pass.

Edge Cases

  • Missing baseline file fails closed.
  • Candidate report remains absent and its digest remains zero before a fresh trial.
  • Existing comparison verification remains authoritative after the trial.
