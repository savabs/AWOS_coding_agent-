Spec: Live Debugger Wiring

Governing research: live_debugger_wiring.html

Contract

Every normal execute_feature() invocation creates .awos/debug/<session_id>/. The session ID is stable for the returned run, and the bundle contains direct lifecycle evidence plus any verifier/test evidence and proof-rule findings observed during execution.

Atomic implementation steps

  1. Initialize a journal and helper emitter at the start of execute_feature(); prove a bundle exists even when optional runtime sessions are disabled.
  2. Record task lifecycle evidence and verifier/test results from the single-task path; prove real failures become journal findings.
  3. Record terminal session evidence and expose the debug session ID in the result; prove successful and failed runs close with readable bundles.
  4. Add an end-to-end controlled orchestrator test without requiring an LLM or external API; prove CLI/inspection can consume the generated bundle.

Non-goals

No rerun executor, no model calls, no provider changes, no OpenTelemetry export, and no change to deterministic proof rules.
