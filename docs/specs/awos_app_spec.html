Spec: AWOS Native App — Electron + Apple Design

doc/spec phase/4 topic/native-app active 2026-07-12

Goal

Ship AWOS as a real desktop application — dock icon, frameless window, native menus, Apple-inspired visual design. The agent console becomes a finished product you can download and open, not a URL you visit.

Implementation Steps

Step 1: awos-app scaffolding
Create awos-app/package.json + install Electron

Create awos-app/package.json with Electron dependency and electron-builder for packaging. Run npm install.

Exit: node_modules/electron installed, npm start prints "Electron"
Step 2: Electron main process
Create awos-app/main.js

Main process that:

  • Spawns gui/server.py as child process on port 8765
  • Polls http://localhost:8765/agent until ready
  • Creates frameless BrowserWindow (1200×800, vibrancy, transparent)
  • Loads agent console URL
  • Sets app menu (File, Edit, View, Window, Help)
  • Handles dock bounce on activity via IPC
  • Cleanup on app quit (kill Python server)
Exit: npm start opens frameless window showing agent console
Step 3: HTML redesign
Redesign gui/static/agent.html

Complete visual overhaul:

  • Frameless title bar with traffic light dots (non-functional, decorative for web, functional in Electron)
  • Left sidebar with frosted glass effect, narrower (260px)
  • Main content with generous padding
  • Thinking panel → "Reasoning Sheet" — slides up from bottom with blur backdrop
  • Event stream → structured cards with smooth entrance animations
  • Apple color palette + typography
  • All existing JS event handling preserved and enhanced
Exit: Open agent.html in browser — Apple-inspired design, thinking sheet, cards animate in
Step 4: Live proof
Run end-to-end verification

Launch the app, verify:

  • Window opens with frameless title bar
  • Agent console loads with Apple-inspired design
  • Dock icon visible
  • Native menus work
  • Quit cleans up Python server
Exit: All markers observed
