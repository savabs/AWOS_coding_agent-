Spec: Live Event Streaming

doc/spec phase/4 topic/live-streaming active 2026-07-05

Goal

Wire the AWOS orchestrator to emit structured events at every phase (planning, routing, task execution, file edits, test results) through GuiEventBus. Replace the polling SSE endpoint in gui/server.py with one that reads new events from .awos/gui/<id>/events.jsonl and pushes them to the browser. The frontend renders each event type differently.

Exit criterion: running awos fix-ci on the wedge corpus while awos serve is active shows live log entries in agent.html as the agent works.

Governing research: live_event_streaming.html
Task file: live_event_streaming.html

Implementation Steps

Step 1
Extend GuiEventBus with event type constants + emit helpers

Add a class EventType with string constants for all 9 event types. Add a emit_() helper method for each that constructs the proper payload dict. Add a class method event_types() returning the set of valid types.

File: scaffold/agent/gui_events.py

Exit condition: pytest tests/test_gui_events.py -q passes (create test: verify emit_* produces correct payload shape, verify EventType constants match event_types())
Step 2
Wire orchestrator to emit events at start and planning phase

In orchestrator.py execute_feature(): after session_id is created, instantiate GuiEventBus(session_id, goal). Store as self._gui_bus. Emit session_start event. After codebase indexing, emit codebase_indexed. After planner returns, emit plan_generated with task list summary.

File: scaffold/agent/orchestrator.py

Exit condition: Run awos fix-ci on wedge corpus (dry mode). Verify .awos/gui/<id>/events.jsonl contains session_start, codebase_indexed, plan_generated events.
Step 3
Emit model_routed and task_start events from task execution

In _execute_single_task() and _execute_task_via_react(): after EscalationEngine returns a decision, emit model_routed with model_name, tier, reason, cost_estimate, provider. Before the worker executes, emit task_start with task_id, action, file, model info.

Pass self._gui_bus reference into these methods (or store as instance var).

Files: scaffold/agent/orchestrator.py

Exit condition: Run awos fix-ci on wedge corpus (dry mode). Verify events.jsonl contains model_routed + task_start events per task.
Step 4
Emit file_edit, test_result, task_complete events

After the react_worker returns with files_changed, emit file_edit for each changed file. After test runner completes, emit test_result. After task result is finalized, emit task_complete with success, cost_usd, n_edits, error.

At the end of execute_feature(), emit session_done with completed, failed, total_cost, elapsed.

File: scaffold/agent/orchestrator.py

Exit condition: Run awos fix-ci on wedge corpus (full run). Verify events.jsonl contains all 9 event types with correct payloads.
Step 5
Replace SSE endpoint to read from events.jsonl

In gui/server.py: Add a new endpoint /api/agent/events that maintains per-session byte offsets. Every 500ms, check the .awos/gui/<latest_session>/events.jsonl file. Read from the last known byte offset. Send any new lines as SSE data: {json}\n\n. If no session is active, send keepalive.

The endpoint should track the latest session by checking .awos/gui/ directories sorted by mtime. When a new session appears, reset the offset to 0 for that session.

File: gui/server.py

Exit condition: Start awos serve. Run awos fix-ci in another terminal. curl http://localhost:8765/api/agent/events shows SSE data lines with event payloads.
Step 6
Update agent.html to render structured events

In agent.html: Change the SSE connection from /api/agent/stream to /api/agent/events. Parse each event.data as JSON. Based on data.type, render differently:

  • session_start → clear terminal, show header banner
  • model_routed → show model card (icon + name + tier badge + reason text + cost estimate)
  • plan_generated → show task count summary
  • task_start → show task header with model info inline
  • file_edit → show file path + diff or diff snippet
  • test_result → colored pass/fail line with test name + duration
  • task_complete → update task line with status + cost
  • session_done → show final summary card

Preserve all existing functionality (history sidebar, stats). Add a "Live" badge indicator when SSE is connected and receiving events.

File: gui/static/agent.html

Exit condition: Open http://localhost:8765/agent while running awos fix-ci. See live log entries appearing in the terminal panel.

Edge Cases

  • SSE connects before orchestrator starts: Session directory doesn't exist yet. SSE polls with 404 → retry every 1s until directory appears.
  • Multiple rapid events: Each emit() writes one line. SSE reads new lines only (byte offset tracking). No race — writes are append-only.
  • Orchestrator crashes: Events up to the crash are persisted. SSE shows "Session ended unexpectedly" when events stop coming for >30s.
  • User refreshes browser: SSE reconnects, reads entire events.jsonl from offset 0 → replays all events.
  • No active session: SSE sends data: {"type":"idle"} keepalive every 5s.
  • events.jsonl missing or corrupt: SSE sends error line data: {"type":"error","payload":{"message":"..."}} and retries.
