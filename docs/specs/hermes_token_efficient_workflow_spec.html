Hermes Token-Efficient Workflow

Goal: reduce repeated context and unnecessary output while preserving reliable coding-agent execution.

Components

  • scripts/build_task_context.py: deterministic bounded packet builder.
  • scripts/session_response.py: compact response/checkpoint formatter and validator.
  • scripts/token_report.py: optional packet and verified-task measurements.
  • AGENTS.md: project-local Hermes operating guidance.

Acceptance

  • Context packets include canonical project facts and only relevant selected artifacts.
  • Context packets have a configurable character budget and deterministic truncation.
  • Malformed response records fail validation.
  • Token reports can measure packet characters/tokens and cost per verified task.
  • All focused tests pass and no global Hermes settings are changed.
