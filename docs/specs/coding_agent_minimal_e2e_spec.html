Spec: Coding Agent Minimal E2E

phase/1 · topic/coding-agent-e2e · active · 2026-07-29

Goal

Prove with one deterministic, zero-API test that AWOS plans a small Python change, rejects an invalid first patch, retries with a valid patch, runs the local test, and returns overall success.

Exit condition: pytest -q tests/test_coding_agent_minimal_e2e.py passes and all assertions below are true.

Atomic implementation steps

Step 1 — Build the isolated temporary repository.

Create calculator.py, test_calculator.py, and pytest.ini under tmp_path. The test expects add(a, b) to return the sum.

Exit: the temporary pytest suite initially fails because the function is absent.

Step 2 — Feed a deterministic plan into the orchestrator.

Patch CheapPlanner.plan to return one task requesting add(a, b); do not pass pre_planned_tasks. Assert the planner was called once.

Exit: execute_feature() receives the fixed plan without a network call.

Step 3 — Simulate one bad worker patch and one corrected patch.

Patch Worker.execute_task with two responses: first a syntactically invalid replacement, then a valid replacement. Disable optional live/ReAct paths and patch auxiliary cheap calls.

Exit: the worker mock is called at least twice and the invalid patch is not written.

Step 4 — Assert real verification, testing, and final result.

Enable the isolated test-runner safety flag. Assert overall success, one completed task, zero failed tasks, final source content, a passing test_result, and a debug journal containing session_done.

Exit: the focused pytest command passes with no external API request.

Edge cases

  • Invalid first patch must leave the original file unchanged before retry.
  • Test runner must not be silently skipped; a skipped result fails the test.
  • Temporary repository state must not modify the project checkout.
  • Planner and worker mocks must not make network requests.
