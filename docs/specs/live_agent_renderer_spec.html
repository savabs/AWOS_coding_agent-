Spec: Live Agent Renderer

Goal: Provide a developer renderer over existing AWOS telemetry.

Atomic steps

  1. Project persisted events into view state.
  2. Serve a dedicated /renderer page.
  3. Stream live events through existing SSE.
  4. Show isolated parallel task lanes.
  5. Show exploration, tools, files, diffs, tests, verification, and debugger evidence.
  6. Prove live and replay behavior with browser smoke tests.

Constraints

No new agent runtime, no provider changes, no hidden chain-of-thought contract, and no dashboard-heavy primary UI.

Exit condition

A programmer can inspect a representative run end to end with no console or network errors.
