Token and Context Observability

Goal

Persist enough per-model-call usage and context telemetry to compare AWOS runs without changing agent behavior.

Files Affected

  • scaffold/agent/model_call_telemetry.py — new append-only record/store.
  • scaffold/agent/usage_record.py — normalize optional usage and record telemetry.
  • scaffold/agent/react_worker.py — capture message categories, tool metrics, timing, and step metadata.
  • scaffold/agent/planner.py — record planner calls.
  • scaffold/agent/worker.py — record patch-worker calls.
  • awos.py — read-only token inspection command.
  • tests/test_model_call_telemetry.py and focused CLI/worker tests.
  • scripts/demo_token_context_observability.py and docs/token_context_observability_proof.md — provider-free live proof.

Atomic Steps

  1. Add a typed best-effort JSONL telemetry store and provider usage normalizer.
  2. Record ReAct calls with context estimates and tool-history metrics.
  3. Record planner and patch-worker calls without changing prompts or provider selection.
  4. Add a read-only CLI aggregate/detail view.
  5. Add unit, integration-boundary, and non-interference tests.

Data Contract

Each record includes provider, model, request type, input/output/reasoning/cache/total tokens, estimated cost, tool-call count, tool-output size, session/task/step metadata, timestamp, latency, and approximate context categories. Missing provider fields remain null or unavailable; estimated fields are labeled.

Live Proof

Run the telemetry demo or a provider-free fixture and observe a JSONL record plus CLI aggregate containing call count, total tokens, context estimates, and unavailable-field labels.

Rollback

Telemetry writes are best effort. Removing the telemetry hook restores prior behavior; no agent state or prompt contract changes are required.
