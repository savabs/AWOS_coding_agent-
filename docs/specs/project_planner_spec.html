Spec: ProjectPlanner — Persistent Goal DAG

doc/spec phase/5C topic/project-planner active 2026-05-19

Goal

Give AWOS persistent memory of multi-session projects by maintaining a Goal DAG at .awos/goals/, so that when the user resumes work on a project the agent knows which tasks are complete, which failed, and which are still pending — without re-running completed work or losing failure history.

Interface Contract

GoalNode Dataclass

@dataclass
class GoalNode:
    goal_id:       str            # UUID4 prefixed with "g_"
    description:   str            # user-supplied goal description
    parent_ids:    list[str]      # empty list for root nodes
    child_ids:     list[str]      # populated when decomposition creates children
    tasks:         list[dict]     # Planner task dicts assigned to this node
    status:        str            # "pending" | "in_progress" | "completed"
                                  # | "failed" | "stalled" | "blocked"
    created_at:    str            # ISO 8601 UTC
    updated_at:    str            # ISO 8601 UTC
    completed_at:  str | None     # ISO 8601 UTC or None
    session_ids:   list[str]      # session UUIDs that touched this node
    failure_count: int            # incremented on each failed attempt (default 0)
    critique_ids:  list[str]      # ErrorPattern task_ids from Phase 5B ReflexionMemory

GoalGraph Class

class GoalGraph:
    root_id: str                  # ID of the root GoalNode
    nodes: dict[str, GoalNode]    # goal_id → GoalNode

    def add_node(node: GoalNode) -> None
    def get_node(goal_id: str) -> GoalNode | None
    def pending_nodes() -> list[GoalNode]   # topological order, no pending parents
    def all_complete() -> bool
    def to_dict() -> dict                   # for JSON serialisation
    @classmethod
    def from_dict(data: dict) -> GoalGraph  # deserialise from JSON

ProjectPlanner Class

class ProjectPlanner:
    def __init__(self, goals_dir: str = ".awos/goals")

    def load_or_create_goal(
        self,
        description: str,
        session_id: str,
    ) -> GoalGraph:
        """
        Find an open goal matching description (Jaccard >= 0.4),
        or create a new root GoalNode and persist it.
        Returns the loaded or newly created GoalGraph.
        """

    def update_node_status(
        self,
        graph: GoalGraph,
        goal_id: str,
        new_status: str,
        task_id: str | None = None,
        critique_id: str | None = None,
    ) -> None:
        """
        Update a node status. Propagates completion/failure to parents/children.
        Writes atomically to .awos/goals/{graph.root_id}.json.
        Updates INDEX.json.
        """

    def append_nodes(
        self,
        graph: GoalGraph,
        new_nodes: list[GoalNode],
        parent_id: str,
    ) -> GoalGraph:
        """
        Append new child nodes under parent_id. Used when:
        - A new request extends an existing goal (goal merge)
        - TaskDecomposer creates sub-tasks from a failing node
        """

    def get_pending_graphs(self) -> list[GoalGraph]:
        """Return all non-completed GoalGraphs from INDEX.json."""

    def summary(self) -> dict:
        """Return {total, by_status, oldest_open} from INDEX.json."""

Implementation Steps

Step 1
Create scaffold/agent/project_planner.py with GoalNode, GoalGraph, ProjectPlanner

Implement the three classes with full docstrings. Include: GoalNode.now_timestamp(), GoalNode.new_id(), GoalGraph.pending_nodes() via topological sort, ProjectPlanner._jaccard(a, b) for keyword overlap, ProjectPlanner._atomic_write(path, data) using .tmp + rename, ProjectPlanner._load_index(), ProjectPlanner._save_index().

Exit condition: python3 -c "from scaffold.agent.project_planner import ProjectPlanner; p = ProjectPlanner('/tmp/test_goals'); print('ok')" prints ok with no errors.
Step 2
Implement load_or_create_goal() with Jaccard goal matching and INDEX.json management

Scan INDEX.json for open goals. For each, compute Jaccard overlap of word-tokenised descriptions (lowercase, strip punctuation, ignore stop-words: "a", "an", "the", "and", "or", "to", "in", "of", "for", "with"). If best score >= 0.4, load and return that graph. Otherwise create root node with new UUID, persist, update index, return new graph.

Exit condition: Calling load_or_create_goal("Add OAuth2 auth") twice returns the same goal_id both times. Calling it with "Add rate limiting" returns a different goal_id.
Step 3
Implement update_node_status() with propagation and atomic write

Update the node in memory. If status == "completed": check if all siblings are complete → update parent. If status == "failed": increment failure_count. If failure_count >= 2: mark child nodes as "blocked". Write to {root_id}.json.tmp then rename to {root_id}.json. Update INDEX.json with new status + updated_at.

Exit condition: After calling update_node_status(graph, node_id, "completed"), re-loading the graph from disk shows the node status as "completed" and completed_at is set.
Step 4
Implement append_nodes() for goal extension and decomposition expansion

Validate parent_id exists in graph. Set new_node.parent_ids = [parent_id]. Append new_node.goal_id to parent.child_ids. Add to graph.nodes. Persist. Return updated graph. Guard: if len(graph.nodes) >= 200, raise GoalGraphFullError.

Exit condition: After appending 2 child nodes under a root, graph.pending_nodes() returns only the 2 children (root is "in_progress"), in topological order.
Step 5
Wire ProjectPlanner into Orchestrator.__init__ and execute_feature()

In __init__: add self.project_planner = ProjectPlanner(). In execute_feature(goal, ...): at the top, call self._active_goal_graph = self.project_planner.load_or_create_goal(goal, session_id=uuid.uuid4().hex). Log: "[ProjectPlanner] goal_id=%s status=%s". No other changes to execute_feature logic in this step.

Exit condition: Running Orchestrator().execute_feature("test feature") creates a .awos/goals/ directory with one JSON file and one INDEX.json. Existing tests still pass (166+ tests).
Step 6
Wire update_node_status() into Orchestrator._execute_single_task() after each task outcome

After worker_success = True: call self.project_planner.update_node_status(self._active_goal_graph, node_id, "completed", task_id=task_id). After max_attempts exhausted: call with "failed". Guard with if hasattr(self, "_active_goal_graph") so the method works standalone. Map task_id to goal_id via a helper _find_node_for_task(graph, task_id).

Exit condition: After a successful task execution, the corresponding node in .awos/goals/{goal_id}.json has status "completed". After a failed task, status is "failed" and failure_count == 1.
Step 7
Add existing_goal param to Planner.plan() to skip already-completed tasks

Add existing_goal: GoalGraph | None = None parameter. If provided, after generating task list, filter out any task whose description closely matches a completed node description (Jaccard >= 0.5). Log skipped tasks: "[Planner] skipping task (already complete in goal graph): %s". Fully backward-compatible — default is None.

Exit condition: Calling planner.plan(goal, existing_goal=graph) where graph has 2 completed nodes returns a task list that does NOT include those 2 tasks. Calling without existing_goal returns the full list.
Step 8
Write tests/test_project_planner.py with full coverage of all public methods

Test classes: TestGoalNode, TestGoalGraph, TestProjectPlannerSaveLoad, TestGoalMatching, TestStatusPropagation, TestAppendNodes, TestEdgeCases. All use tmp_path fixture so no disk pollution.

Exit condition: pytest tests/test_project_planner.py -v reports 25+ tests passing, 0 failures.
Step 9
Run full test suite — zero regressions

Run all existing tests plus the new test file. Confirm 0 regressions against the 166 previously passing tests.

Exit condition: pytest tests/ -v --tb=short shows 190+ tests passing (166 existing + 25+ new), 0 failures, 0 errors.

Edge Cases

  • Empty INDEX.json or missing goals dir: load_or_create_goal() creates the dir and a fresh index. Never raises.
  • Corrupt .json file (partial write crash): On load, catch JSONDecodeError → log warning → treat as non-existent → create new goal. The .tmp pattern prevents most corruption.
  • goal_id collision (UUID): Statistically impossible with UUID4 (2^122 space). No guard needed.
  • Node not found in _find_node_for_task(): Return None, log warning. Do not raise — must not block the retry loop.
  • Graph has 200+ nodes: append_nodes() raises GoalGraphFullError. Orchestrator catches it, logs, continues without appending.
  • User calls execute_feature() without a goal string: Use goal = "unnamed_goal" as fallback — always creates a new graph.
  • Jaccard match on very short descriptions (1-2 words): Short descriptions are inherently high-overlap. Apply minimum description length guard: descriptions shorter than 3 meaningful words always create a new goal.
