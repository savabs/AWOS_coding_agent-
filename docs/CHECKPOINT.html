1 · Objective & Philosophy

Goal: Multiply model effectiveness 10× through scaffolding — not bigger models. Keep cost under $20/month at scale. The model is the CPU; AWOS is the OS.

The user requested a comprehensive audit of the AWOS coding agent covering:

  • Fix all loopholes, pricing errors, and API bugs
  • Implement a smart escalation ladder (cheap → expensive only when needed)
  • Add intelligence amplifiers: chain-of-thought, self-verify, few-shot, symbol context
  • Add cost guardrails and a live budget monitor
  • Dogfood the agent on itself in a sandbox under $0.50
  • Interactive chat interface — no CLI flags exposed to users

6 · Advanced Intelligence Tricks — All Active

⛓ Chain-of-Thought Prefix
Every worker prompt begins with a structured reasoning scaffold: understand task → identify anchor → write SEARCH/REPLACE → verify. Forces step-by-step reasoning before output.
Active
🔍 Self-Verification
After generating SEARCH/REPLACE, worker checks search_str in file_content before calling Verifier. Catches hallucinated SEARCH strings before they waste a round-trip.
Active — 2 retries max
📖 Few-Shot Example Injection
ExampleStore retrieves past successful SEARCH/REPLACE pairs by keyword overlap. Injected into worker prompt as format references. Grows with every successful task.
Active — top 2 examples
🗺 Symbol Context
SymbolIndex extracts all class/function names + import graph across all .py files. Injected into planner and worker prompts so models know real symbol names.
Active
💾 Prompt Caching
Anthropic cache_control on stable system instructions in planner.py. Repeated planning calls hit cache at ~10% of input cost.
Active — Anthropic only
🔄 Response Cache
TTL-based deduplication in UnifiedAgent. Identical or near-identical requests hit cache (free). 15-min TTL, MD5 key on normalized input.
Active — 15-min TTL
📈 Escalation Engine
5-tier model ladder — starts cheap, escalates on evidence. Gates: complexity score, consecutive failure count, budget remaining, explicit user keyword.
Active — all 5 tiers
📚 Session Memory
Hybrid strategy: recent messages kept in full, old messages summarized. Session saved to disk and resumable with --resume <id>.
Active

7 · Guardrails & Budget Monitor

How it works

TriggerAction
Spent ≥ 100% of budgetHard stop — all API calls blocked, clear error message returned to user
Estimated cost of next call > remaining budgetHard stop before the call is made
Spent ≥ 90% of budgetWarning printed before each call, but not blocked
Budget threshold crossed (50% / 75% / 90%)One-time alert printed (fires exactly once per threshold)
