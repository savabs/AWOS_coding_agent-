3. DeepSeek V4 Model Issues

  • Outputs reasoning_content (chain-of-thought) before content — eats tokens
  • Needs max_tokens=4000 (vs 1500 for Claude)
  • Sometimes generates long reasoning that exhausts token budget
  • _parse_action handles it but some responses still fail

4. What STILL Causes Empty Patches

  • Agent can't figure out the edit — explores correctly but doesn't produce a patch (60% of failures)
  • Python version incompatibilities (datetime.UTC in Python 3.10, typing.Self in Python 3.10-3.11)
  • C extension build failures (astropy, matplotlib need python3-dev headers)
  • Shell tool path issues (relative vs absolute paths in tool calls)
  • Agent gets stuck in "file not found" loops (after workdir reset, path confusion)

Key Decision: Stop Chasing Benchmarks

We have a validated 50% on SWE-bench Lite with DeepSeek at $0.08/instance. That's competitive with Aider (~25%) using a cheaper model.

The gap between 50% and 65% (mini-SWE-agent) is mostly model quality, not agent architecture. We can't close that gap without working Claude/GPT APIs.

Focus should shift to:

  1. Proving the self-learning loop works (our MOAT)
  2. Building a beautiful UX that showcases what the agent does
  3. Cleaning up technical debt so iteration is faster
