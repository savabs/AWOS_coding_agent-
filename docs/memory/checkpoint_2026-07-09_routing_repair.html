3. What was implemented (so far)

Step 1: Weight Versioning ✅

Filescaffold/agent/ml_router.py
ChangeRewrote _save() and _load() methods
Details
  • _save(): adds "format_version": 2 to payload
  • _load(): checks format_version. V1 (no key): only loads on exact n_actions match (backward compat). V2+: handles mismatch by padding (more current actions → new actions get identity A, zero b → explore freely) or truncating (fewer current actions → drop extra).
  • Logs: "loaded v2: X updates, padded Y→Z actions" or "truncated Y→Z actions"
  • Feature dimension mismatch → still starts fresh (can't pad features)
  • Added guard for _weights_path is None in both save and load

Step 2: ReplayGate Fixes ✅

Filescaffold/agent/reward_store.py
ChangeReworked ReplayGate scoring and threshold logic
Details
  • Adaptive threshold: threshold changed from fixed attribute to @property. Formula: max(0.15, base_threshold - 0.01 * sqrt(total_episodes)). At 0 episodes=0.40 (strict), at 500=0.18, at 1600=0.15 (floor).
  • Weighted scoring: changed from equal (1/3 each) to: inform*0.4 + novelty*0.2 + boundary*0.4. Novelty weight halved because coding tasks are inherently repetitive.
  • Tracking: added _total_episodes and _admitted_count counters. Every 100 episodes: log [replay_gate] N episodes processed, admit rate=X%, threshold=Y.
  • admit_rate(): new method returning fraction admitted so far.
