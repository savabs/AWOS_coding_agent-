Checkpoint: Token and Context Observability

Date: 2026-08-20

What Changed

  • Added best-effort append-only per-model-call telemetry at .awos/model_calls.jsonl.
  • Instrumented primary ReAct, planner, and patch-worker OpenCode calls.
  • Added context-category estimates, tool-history metrics, latency, identifiers, and optional provider usage fields.
  • Added read-only awos tokens CLI inspection.
  • Added provider-free live proof and focused tests.
  • Added ReAct history compaction (_compact_messages) to bound prompt growth from O(turns^2).
  • Added retrieval-first task prompt: replaced 5,000-char blind file injection with an 800-char orientation snippet + repo-map read-window pointer.
  • Centralized the static prefix (_static_prefix = system + task prompt) as the invariant leading prefix that provider prefix-caching keys on.
  • Telemetry now aggregates cache-read/cache-write/reasoning tokens; surfaced in awos tokens.
  • Added observation summarization (_summarize_observation): run_tests, grep, read_file, shell, and error outputs are collapsed into compact high-signal observations; raw text remains the fallback for other tools.
  • Telemetry/CLI now report cache_hit_rate (cache_read / input tokens) to measure provider prefix-caching effect per run.
  • Added disk-first fail-safe file resolution (resolve_file.py): exact → basename → case-insensitive → grep. Index hints (repo map primary-file) are now NEVER authoritative — a stale hint falls back to real filesystem search, so an existing file can never be hidden by a bad index.
  • Added persistent symbol index: save()/load()/rebuild_changed() (mtime-based incremental), line-numbered symbol bodies (symbol_lines) in both ast + tree-sitter parsers, compact_map() + symbol_windows().
  • Added index_retrieval.py: disk-grounded hierarchical retrieval — bounded symbol_map (level-1) + on-demand read_windows (level-2) from a per-repo persisted index; every entry verified against disk via resolve_with_evidence, stale entries dropped.
  • Wired retrieval into enrich_with_repo_map and the ReAct task prompt (symbol map + READ WINDOWS addressing read_file).
  • Added GUI chat sliding-window context in gui_chat.py: _conversation_messages keeps recent turns verbatim (env-tunable AWOS_CHAT_RECENT_TURNS, capped by AWOS_CHAT_MSG_CHARS) and collapses older turns into a single compact summary (AWOS_CHAT_SUMMARY_TURNS). A 20-turn chat now sends a bounded prompt instead of the full history.
  • Added honest test verdicts in test_runner.py: subprocess returncode is captured on TestResult and is the authoritative pass/fail signal — a nonzero exit overrides a superficially-passing output parse (pytest/jest/vitest/generic). Added _execute_targeted to target changed pytest test files via changed_files.
  • Added edit-safety: EditFileTool (ReAct path) now computes the candidate content and validates Python syntax BEFORE writing, so invalid code is never left on disk (previously wrote-then-validated). New-file creation and blank-file overwrites are also guarded.
  • Added verifier ambiguity rejection: fuzzy tier-4 now rejects near-tie matches (runner-up within 5% of best), returning a specific "ambiguous" error instead of guessing a location.
