💰 Cost Analysis

New Dependencies

chromadb>=0.4.0                    # Free (local vector DB)
sentence-transformers>=2.2.0       # Free (local embeddings)
# Optional:
# google-generativeai>=0.5.0       # Already have (for cheap thoughts)

Runtime Costs

  • Embeddings: Local model (all-MiniLM-L6-v2) = $0
  • Vector DB: ChromaDB (local) = $0
  • Thoughts: Gemini Flash = $0.0001/1k tokens (vs $0.003 for Sonnet)
  • Verification: Gemini Flash = $0.0001/check
  • Total overhead: ~$0.0005/request (0.5% of current cost)

Storage

  • Vector DB: ~1MB per 100 interactions
  • Traces: ~10KB per session
  • Total: <100MB after 10,000 interactions

🔧 Technical Decisions

Decision Chosen Alternative Rationale
Embedding model all-MiniLM-L6-v2 (local) Gemini embeddings (API) Free, fast, good enough (384 dim)
Vector DB ChromaDB FAISS, Qdrant Persistent, easy, <1M vectors
Reasoning model Gemini Flash (separate) Same model as actions 100x cheaper for thoughts
Trace storage JSON files SQLite Simple, grep-able, no DB
Verification Syntax + LLM check Full test execution Fast, catches 80% of issues

🎓 Key Learnings

  • The model is the CPU, we're building the OS — Scaffolding matters more than model size
  • Memory = learning — Without persistent memory, every session starts from zero
  • Transparency = debuggability — Can't improve what you can't see (ReAct traces)
  • Verification > generation — Catching errors is cheaper than fixing them later
  • Local > API when possible — Embeddings, vector DB can be free and fast
  • ROI-driven prioritization — Vector memory (10x impact, 4h effort) beats parallel exec (2x impact, 8h effort)
