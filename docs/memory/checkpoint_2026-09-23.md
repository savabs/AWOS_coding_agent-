## Bugs found and fixed

- **`--max-cost` could never trip while recording.** `RecordingClient` did not
  expose the inner client's `model`, so `AgentLoop.model_name` read `"replay"`
  and priced a paid run at $0. The only mode that spends money had no working
  per-run cap. Fixed; regression test
  `test_cost_cap_still_trips_while_recording`.
- **Cassette root normalisation failed on macOS.** `_fingerprint` replaced only
  the *resolved* root (`/private/var/...`) while tool output shows the given
  one (`/var/...`), so replay silently degraded to ordinal fallback. This was
  the pre-existing failure of `test_replays_exactly_in_a_different_directory`.
  Fixed by normalising both forms. The recorded cassettes were re-keyed
  offline (32 turns; replies untouched) and now replay with **0 misses**.

Suite: `pytest tests` → 37 failed / 1093 passed, the same 37 pre-existing
failures as before; none in cassette, agent loop or benchmark code.
