Checkpoint — Assistant Live Observer Implementation

2026-07-28 · Phase 1 · immutable session record
Source of truth for next session:
tasks/active/assistant_live_observer.html and docs/specs/assistant_live_observer_spec.html.

What changed

  • Added scaffold/agent/observer_protocol.py: versioned envelope validation, stable event IDs, bounded JSON payloads, correlation fields, assistant-safe allowlisting, secret redaction, malformed-line isolation, cursor-compatible projection.
  • Updated scaffold/agent/gui_events.py: existing GuiEventBus now persists observer envelopes with per-session sequence cursors, resumes sequence after reopening, carries chat/trace/task IDs, and marks internal diagnostics developer-only.
  • Updated chat/orchestrator correlation: gui_chat.py creates a trace ID, exposes it in stream responses, and passes chat/trace IDs to orchestrator.py; task events carry top-level task IDs.
  • Added semantic UI telemetry in gui/static/chat.js and gui/server.py:
app open, view change, chat submit metadata, session selection, task control, and response lifecycle. Raw prompt text and keystrokes are not emitted.
  • Added observer APIs: /api/observer/events, /api/observer/stream, /api/observer/snapshot, and /api/observer/ui-event.
  • Added read-only CLI commands: python3 awos.py observe snapshot and python3 awos.py observe events.
  • Migrated gui/static/renderer.html to snapshot/replay/observer SSE while preserving its developer projection; updated its renderer contract test.
  • Added focused observer coverage in tests/test_assistant_live_observer.py.
