## Key Design Decisions

| Decision | Rationale |
|---|---|
| `DEPS_AVAILABLE` check uses `except Exception` not `except ImportError` | PyTorch version mismatch raises `NameError`, not `ImportError` |
| Import check treats third-party missing as warnings | Avoids false positives with optional deps (e.g. `requests` might not be installed) |
| Contract compliance extracted to shared helper | Both `SelfVerificationEngine` and `Verifier` use identical logic; DRY |
| Self-verify runs in-memory only | Never writes to disk; Verifier still handles the actual disk apply + full lint |
| Vector Memory collections: `codebase_chunks` + `session_memory` | Semantic code retrieval + episodic outcome memory for cross-session learning |
| Graceful degradation everywhere | `if self.vector_memory is not None` guards; system works identically when deps absent |
