Design boundary

The new store is not yet wired into the full orchestrator. AWOS already has RuntimeSession as an execution cursor and DebugJournal as a debugger audit bundle. Replacing or duplicating those paths without an adapter contract would be unsafe. The next task should define the mapping and single-owner rule before integration.
