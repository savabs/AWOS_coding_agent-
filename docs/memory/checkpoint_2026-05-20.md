## What Was Completed This Session

### Phase 1 — Observability Foundation (36 tests)
- **`scaffold/agent/core/observability.py`** — `TaskSpan`, `ObservabilityStore`, `MetricsSummary`
- `TaskSpan` captures: enqueue/routing/worker/complete timestamps, model, escalation, strategy, attempt_count, success, input/output tokens, cost
- Derived properties: `queue_wait_ms`, `worker_latency_ms`, `total_latency_ms`, `total_tokens`
- `ObservabilityStore` persists spans to `.awos/spans.jsonl` (append-only JSONL)
- `MetricsSummary.display()` prints: p50/p95/p99 latency, success rate, throughput, cost/MTok, model distribution
- `new_span()` factory helper for orchestrator use
- Wired into `orchestrator._execute_single_task` (stamp on enter/exit) and `execute_feature` (print summary)

### Phase 2 — Queueing Theory (36 tests)
- **`scaffold/agent/core/queue_model.py`** — `MM1Queue`, `QueueState`, `RegretTracker`, `RegretState`
- `MM1Queue.from_spans()`: estimates λ (arrival rate), μ (service rate), ρ=λ/μ, Wq, W, Lq, L from span timestamps
- Saturation warning at ρ ≥ 0.80; stability flag; min 3 samples gate
- `RegretTracker.from_episodes()`: pseudo-regret against oracle action, avg regret/episode, theoretical O(√T·log K) bound, per-action mean rewards
- `ObservabilityStore.queue_state(window=100)` added

### Phase 3 — Inference Visibility (48 tests)
- **`scaffold/agent/core/inference_profile.py`** — `TokenProfile`, `InferenceReport`, `InferenceProfiler`
- Prefill/decode decomposition from `input_tokens`, `output_tokens`, `worker_latency_ms`
- Estimates: TTFT ≈ worker_latency × prefill_ratio, TPOT ≈ decode_ms / output_tokens
- Workload classification: `prefill_heavy` (>65%), `decode_heavy` (<35%), `balanced`
- **Prompt cache savings**: 90% × prefill_ratio × cost_usd per task
- Batching model: T(B) = B / (1 + 0.15 × log₂(B)) — continuous batching (PagedAttention)
- Per-model prefill ratio breakdown
- `ObservabilityStore.inference_report(window=100)` added

### Phase 4 — Async Systems (58 tests)
- **`scaffold/agent/core/async_engine.py`** — `CircuitBreaker`, `BackpressureQueue`, `AsyncProjection`
- `CircuitBreaker`: CLOSED/OPEN/HALF_OPEN FSM, rolling window failure rate, configurable threshold/timeout/window/min_calls
  - `call(fn)` wrapper, `record_success/failure()` manual API
  - `CircuitOpenError` raised on rejected calls (fail-fast)
- `BackpressureQueue`: `asyncio.Queue` wrapper with REJECT policy; `put()` returns False instead of blocking when full; `metrics` property
- `project_async_gains(spans, n_workers)`: predicts ideal/realistic speedup, circuit breaker overhead, queue rejection rate, cache savings
- `ObservabilityStore.async_projection(n_workers=4, window=100)` added

## Key Design Decisions

| Decision | Rationale |
|---|---|
| Dynamic imports in ObservabilityStore methods | Avoid circular deps at module load time |
| `inference_report()` before `async_projection()` | Phase 3 cache savings feed Phase 4 display |
| CircuitBreaker sync-only | Works in both sync and async contexts without requiring await |
| BackpressureQueue REJECT policy (not BLOCK) | Saturated AWOS should signal caller, not deadlock |
| `timeout_s=0.0` guard in tests via `_state` | `state` property re-transitions OPEN→HALF_OPEN when 0s timeout; test checks `_state` directly |
| All 4 phases gated with `if x is not None` | No output when spans file doesn't exist yet (fresh installs) |
