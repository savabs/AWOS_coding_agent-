    Graph contract fix

    The first fix hardcoded the five fields. That was recognized as too rigid. The design was upgraded:

    • Strict execution core remains controlled by AWOS
    .
  • New
    • planner_metadata envelope accepts bounded JSON-like advisory data. >Unknown metadata keys are preserved instead of rejected.
  • Unknown metadata cannot create nodes, change
    • paths, dependencies, retries, tests, permissions, or commands.
  • The five old top-level fields migrate into metadata for compatibility.
  • Duplicate legacy and metadata fields fail closed.
    • >Metadata has bounds for depth, key count, list count, string length, and total size.
  • Only known worker-contract hints are rendered into the worker prompt.
  • New
    • executable behavior still requires an explicit versioned AWOS contract change.
  • Qwen’s prompt now asks for advisory
    • information inside planner_metadata.
