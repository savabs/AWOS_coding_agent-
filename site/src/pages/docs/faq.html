FAQ

Does my code leave my machine?

Only the context sent to the model provider you choose. With a local model and --privacy local_only, nothing leaves. See Security and privacy.

Can it break my repo?

It never edits your checkout and never pushes. All work lands on a separate local branch you review, merge or delete.

What kinds of tickets work best?

Well-defined bugs, small features, test writing, refactors and migrations with a clear definition of done. Vague product decisions still need you.

Which languages does it support?

The worker's own test check runs pytest, and the measured results are on Python projects, so Python repositories with tests are where AWOS is proven today.

How much does a ticket cost?

On 73 real GitHub issues, Claude Haiku 5.5 averaged $0.0071 per issue. A local model costs $0 per ticket. Every job has a dollar cap you set. See Models and cost.

Can I use it without any cloud model?

Yes. Run a local model server and set AWOS_PROVIDER=local. In our check, Qwen3.5 9B on a 16 GB MacBook solved 8 of 10 easy issues, slowly. It is best for routine fixes queued overnight.

What happens if my API key stops working overnight?

Jobs pause as blocked instead of failing, you get one notification, and they resume once the key works again. You can also run awos unblock <id>.

How is this different from an interactive coding assistant?

AWOS is built to run unattended through a queue, check its own work, and hand you finished branches, instead of pairing with you in a chat.

How do I get it?

AWOS is in early access and free while it is. Request access and we will send the install command.
