    Get alerts on this phone (ntfy)

    When a run needs you, your Mac sends a short alert through ntfy. The alert only says "AWOS needs you: open the AWOS phone page". No codes, no portal names.

    Your topic:

    iPhone: install ntfy from the App Store → open it → + → paste the topic → leave the server as ntfy.sh → Subscribe. Allow notifications when asked.

    Android: install ntfy from Google Play or F-Droid → + → paste the topic → Subscribe. Allow notifications when asked.

    Tapping an alert opens this page. Anyone who knows the topic can read or send alerts on it, which is why it carries nothing private.

    Forward SMS codes automatically

    Forwarded texts are the one part that is not end-to-end encrypted: an iPhone Shortcut cannot encrypt. The text goes over HTTPS to the AWOS relay, is cut to 500 characters, kept at most 10 minutes and deleted as soon as your Mac reads it. Forward only texts with codes.

    iPhone (Shortcuts)

    1. Open Shortcuts → Automation → + (New Automation) → Message.
    2. Message Contains: code. Choose Run Immediately (turn off Notify When Run if you like) → Next.
    3. New Blank Automation → Add Action → search Get Contents of URL.
    4. Tap the URL and paste the address above.
    5. Tap ›: Method = POST. Headers → Add new header: key X-AWOS-Token, value = the token above.
    6. Request Body = JSON → Add new field → Text: key text, value = tap and choose the Shortcut Input variable, then tap it and pick Content (the message text). → Done.
    7. Repeat steps 1 to 6 with OTP and verification (one word per automation: Shortcuts matches one phrase each).

    Android (MacroDroid)

    1. Install MacroDroid from Google Play → Add Macro.
    2. Trigger + → Phone/SMS → SMS Received → Any contact → Text contains: code (add more triggers for OTP, verification). Allow the SMS permission.
    3. Action + → Connectivity → HTTP Request. Method POST, URL = the address above.
    4. Headers tab: add X-AWOS-Token = the token above.
    5. Body: content type text/plain, body = the [sms_message] magic text (tap the ⋯ / magic text button → SMS message text).
    6. Name it "AWOS codes" → save (✓). Keep MacroDroid allowed to run in the background (Settings → Battery → no restrictions).

    Android (Tasker, alternative)

    1. Profiles + → Event → Phone → Received Text → Type SMS; Content *code*/*OTP*/*verification*.
    2. New task → + → Net → HTTP Request: Method POST, URL = the address above, Headers X-AWOS-Token: + the token, Body %SMSRB, Mime Type text/plain.
    3. Back out to save; make sure the profile is on.

    Test it: text yourself "test code 1234". Within a few seconds your Mac's AWOS Replay shows it under Phone.

    How this works

    Your Mac and this page share a secret key from the pair link. The part after # is never sent to any server. Messages between them go through the AWOS relay already encrypted (AES-GCM), are kept at most 10 minutes and are deleted once handled. Captchas and logins cannot be done from here yet: those cards tell you which portal to finish at your Mac.
