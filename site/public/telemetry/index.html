Privacy

What AWOS sends, if you say yes

Usage counts are off unless you opt in. AWOS asks once during setup; the default answer is no. Change it any time:

awos telemetry on
awos telemetry off
awos telemetry status

The whole payload

{"v": 1,
 "event": "install" | "first_run" | "job_finished",
 "install_id": "random uuid4, made when you opt in",
 "awos_version": "0.2.2",
 "os": "darwin" | "linux" | "windows" | "other",
 "outcome": "solved" | "failed" | "cancelled",
 "duration": "lt1m" | "1to5m" | "5to15m" | "15to60m" | "gt60m",
 "cost": "zero" | "lt1c" | "1to10c" | "10cto1" | "gt1",
 "provider": "anthropic" | "local" | "other"}

The last four fields are only on job_finished (and provider on first_run).

Never sent

Code, diffs, prompts, goals, test output, repository or file names, paths, branch names, API keys, host or user names. The install id is random, not derived from your machine, and turning telemetry off forgets it.

What we keep

The server keeps daily totals only, such as "12 jobs solved on linux today". It does not store your IP address or install id. Pings are also off when DO_NOT_TRACK=1 or AWOS_TELEMETRY=0 is set.
