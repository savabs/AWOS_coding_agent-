Quickstart

Install with one line, open AWOS in your repository, and type what you want done. It works in the background and shows you the result to review.

Requirements

  • macOS or Linux. The installer sets up Python 3.11+ for AWOS if you do not have it.
  • A git repository to work on. Test verification uses pytest, so a Python repo with tests gets the most out of the report.
  • A model: an Anthropic API key, or a local model server (see Models and cost).

1. Install

curl -fsSL https://awos.tirramind.com/install.sh | sh

The installer uses uv or pipx if you have one, never uses sudo, and never edits your shell files. If the awos command is not on your PATH yet, it prints the one line to add.

Prefer to install by hand?

pipx install "git+https://github.com/savabs/AWOS_coding_agent-@v0.2.2"

2. Open AWOS in your repo

cd ~/code/your-repo
awos

The first time, AWOS asks which model to use. Paste an Anthropic API key (it is checked for free and stored in ~/.awos/.env, readable only by you), or choose a local model. It also detects your test command. Run awos doctor any time to check your setup.

3. Type a task

awos › fix the date parser so 2024-02-29 is accepted
  + queued 826bb90c (starting now)
    reading dates/parse.py
    writing acceptance tests (2 kept)
    running tests… 14 passed
  ✓ done  826bb90c  tests 14 passed · $0.004 · 41s · branch awos/826bb90c
      [d]iff  [m]erge  [r]eject  [f]ollow-up  [o]pen report

Type as many tasks as you like; they queue and run one at a time in the background. You can keep typing while one runs. Close the terminal and the jobs keep going; open awos again to see what finished.

4. Review the result

  • d shows the diff.
  • m merges the branch into your current branch. AWOS refuses if your uncommitted changes touch the same files.
  • r deletes the branch after you confirm.
  • f asks for a follow-up that starts from this branch, for example "also handle the time zone".
  • o opens the report: goal, test results, cost, time and anything it was unsure about.

Nothing is merged, deleted or pushed unless you press the key.

One-shot and scripting

# one task, wait for it, then review
awos "add a median() function to stats.py with a test"

# queue from scripts or CI; the worker runs it in the background
awos submit --repo . --budget 0.50 "bump requests to 2.32 and fix any breakage"
awos status --digest

See the CLI reference for every command.
